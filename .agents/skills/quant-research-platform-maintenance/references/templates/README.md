# QRP Task Templates

Use the smallest template matching the task mode. Do not load all templates by default.

| Template | Mode |
|---|---|
| `auto-task-router.md` | short or ambiguous prompts |
| `focused-implementation.md` | standard bounded implementation |
| `focused-audit.md` | review-only / independent audit |
| `goal-closure.md` | long goal / review-fix loop |
| `handoff-packaging.md` | review bundle / handoff package |
| `git-operations.md` | commit, push, merge, branch cleanup gates |
| `docs-status-sync.md` | active docs/status/brief sync |
| `apply-only-validation.md` | apply external patch/zip exactly and validate |
