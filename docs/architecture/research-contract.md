# 研究合同

本文件描述 QRP 研究层长期合同。

## 研究对象

QRP 支持本地量化研究流程，包括数据、因子、特征、标签、模型、预测、信号、评估、组合和报告。

## 命名边界

- factor 是研究信号来源。
- feature 是模型输入或因子变换后的建模字段。
- label 是监督学习目标。
- prediction 是模型输出。
- signal 是评估或组合使用的排序、权重或交易意图输入。
- evaluation 衡量信号或预测的研究表现。
- 评估轴必须符合研究横截面：多资产同一时点使用
  `cross_sectional`；单资产 HFT 跨时点使用 `single_asset_time_series`，
  不得用零有效观测的横截面结果冒充通过。当前单资产评估轴使用有界在线矩计算跨时间
  Pearson 相关系数；在尚未实现精确、有界的排名/分组评估时，将 RankIC 与分组价差
  明确标记为不适用，不输出伪精确值。
- portfolio 处理组合构建和收益路径。

## 当前合同唯一

同一语义只能有一个当前入口。平行入口需要用户批准，并由对应合同测试覆盖责任模块、
生命周期和收敛条件。

## 层边界

research 持有研究数学、因子/标签定义及正式研究协议，可以依赖 contracts、storage 和 runtime resources。
research 不得依赖 `markets/implementations/` 或 `sources/`。
A 股与 Crypto 的研究场景由 `research/protocols/` 持有；`profiles/` 只做协议、目录、生产器及
市场/来源实现的组合绑定。对应 `markets/implementations/` 持有市场事实与执行机制。

compute 只提供数值计算核心，不持有市场会话领域工具，也不写报告或存储产物。

reports 是纯报告内容责任模块，可由 workflows 或负责持久化的 artifacts 调用；
artifacts 只验证并写入内容，不反向定义报告语义。允许 `artifacts -> reports`，
仍禁止 `reports -> artifacts`，避免内容层依赖物理产物层。

可移植的模型算法 ID、默认/冒烟参数、依赖包、输入种类与并行分类事实由 contracts 持有；
拟合、预测、特征重要性、排名集成与验证行为由 research 中对应责任模块持有。
单个算法字段使用 `model_algorithm`，算法 ID 集合使用 `model_algorithm_ids`。

公开包接口面由唯一活动合同管理；内部辅助函数只在真实调用方需要时保留，
不以名称、可见性或重新导出形式作为验收门槛。

模型选择的指标、方向和无警告行为必须由合同与责任层测试保护，
运行器不维护平行事实源。A 股生产链由同一目标 DAG 顺序持久化研究数据集、因子评估、
季度模型选择/重新拟合以及 OOS 预测；预测只读取已发布的模型产物。

未接入当前生产路径的延期实现、脚手架和测试不保留；仍有产品价值时只记录未完成事项。

## 数据安全

研究证据不能泄漏本地专用的行级数据。可交接结果只能包含统计摘要、结构、计数、哈希、
状态和已清洗的逻辑路径。

## 业务扩展边界

新增模型、因子、执行模式、产物类型或报告合同，必须有明确的责任层、输入输出合同、
测试和验证计划。未经批准，不新增交易执行或外部连接器能力。
