# Architecture docs（架构文档）

本目录保存 QRP 长期架构说明。日常 Codex 任务不要默认读取全部文件；先从 `AGENTS.md` 和 `.agents/` 路由，再按需进入本目录。

## 推荐阅读顺序

1. `agent-governance.md`：智能体治理总览。
2. `agent-governance-file-guide.md`：用人话解释治理目录和文件。
3. `ai-native-engineering-principles.md`：AI-native 工程原则，属于长期参考，不是日常 prompt。
4. `engineering-standards.md`：工程标准。
5. `environment-contract.md`：环境合同。
6. `quant-research-standards.md`：量化研究标准。
7. `next-stage-roadmap.md`：后续路线图。
8. `open-issues-register.md`：开放问题登记。
