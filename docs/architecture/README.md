# Architecture Documents / 架构文档

本目录收拢 `quant-research-platform` 的架构蓝图、能力池和工程治理规则。

阅读顺序：

1. [handoff-before-directory-rename.md](handoff-before-directory-rename.md)：目录改名前和新对话启动时的最短交接入口。
2. [future-capabilities.md](future-capabilities.md)：未来要做什么，以及哪些能力不属于当前已实现范围。
3. [target-directory-structure.md](target-directory-structure.md)：这些能力最终放在哪里，以及 Phase 1 / Phase 2 / Future 的阶段边界。
4. [engineering-standards.md](engineering-standards.md)：模块依赖、合同、版本、错误、配置、测试、扩展和生成物规则。
5. [quant-research-standards.md](quant-research-standards.md)：point-in-time、universe、tradability、成本、容量、统计验证和复现规则。
6. [architecture-refactor-design.md](architecture-refactor-design.md)：当前这一轮 contract-first 架构重构设计。
7. [phase-1-implementation-checklist.md](phase-1-implementation-checklist.md)：把 Phase 1 重构设计拆成可执行任务、验收项和测试矩阵。

本目录中的文档是设计和治理依据，不代表所有目录或能力都已经实现。
