# 近重复因子的经典代表

原生因子目录只保留本页所述代表，舍弃项不提供别名或兼容计算。分类不限制其余可计算输入；不增加 PCA、聚类运行器、训练期相关性筛选或预选因子集合。来源事实仍按原数据边界保留，历史报告保持当时的因子定义与结果。

## 选择依据

这是依据已有探索数据作出的研究设计取舍，不是数学恒等声明，也不是以收益标签挑选因子。公共序列按日期一次计算；个股候选按实际进入模型的风险中性化、标准化表示逐日复核。全历史诊断参与了设计，后续历史回测不能据此称作完全未触碰的盲测。

公共同源候选要求绝对 Pearson 与 Spearman 均至少 0.995，至少三个可评价年份且每年绝对 Spearman 至少 0.99，并确认代表覆盖舍弃项的已有有效观察。仅排序相同、幅度差异明显，或不同来源的发布时点、期限及经济含义不同，不足以删除。

股票候选使用完整合格截面复核：绝对 Pearson 与平均每日绝对方向一致的 Spearman 至少 0.995，各年平均每日相关的绝对值至少 0.99，代表不损失已有覆盖。该筛选没有声称逐一穷举所有列对，也没有将所有高相关情形视为经济等价。

扩大日频定位至658个每周截面、84,224条观察后仍定位到原21对候选，未增加满足条件的删除项。
高频两日22个时点、11,264条股票观察中，137个可变输入只定位到行业相对60秒收益与个股60秒收益一对：
Pearson约0.99466，截面秩相关约0.99743；覆盖时间短且幅度相关未达门槛，保留两者。
这是抽样定位及公式复核，不是全部历史、全部证券的相关矩阵穷举。

原57个公共候选只按秩相关定位，其中本次联合条件支持20对，另外7个公共删除项来自更完整的覆盖比较。
其余37对保留：例如IORB两种标准分的Pearson仅约0.186，香港结余标准分约0.548，SHIBOR3个月约0.983；
高秩相关不能掩盖数值幅度差异。中国期限利差两种标准分总体Pearson约0.99918，但最差年份秩相关约0.98065；
M2对应最差年份约0.959，尚不适合全时期删去。

高频盘口近远档OFI之差和买卖盘深度斜率之差可以由多列线性重构，但不是与单一代表近重复。
它们可能帮助树模型表达对比关系，继续保留。成交强度与平均间隔分别使用49/50个间隔，撤单量比例与撤单笔数占比的分母也不同；不按名称相近删除。

## 实现与消费

宏观配方由 research/factors/macro_liquidity/definitions.py 负责，行业配方由 market_structure.py 负责，量价配方由 price_volume/definitions.py 负责。通用数值算法仍供保留因子使用；不在模型中另设黑名单维护第二套规则。

新计算使用缩减后的原生目录。已完成的股票模型输入通过列投影复用原值、处理值、样本、标签和时钟，删除相应原值及全部派生表示；无需重新估计保留因子。旧输入和旧模型作为对应历史实验保留，新模型从更新后的原生输入自动派生候选列。

本次 A 股低频候选数由 1311 降为 1276，其中市场公共特征 939 列、个股或行业特征 337 列。各训练窗口继续依据自己的成熟训练样本排除全缺失及常数列，实际输入数因此可以更少。该数量不是独立信息维数。

按经济定义选代表与按目标预测力筛选是不同操作。本次不按全历史 IC、模型重要性或验证收益删除其他因子，也不因为列数下降就机械调整网络深度或宽度。
