# 架构与接口说明

本文说明每项操作负责什么、如何连接输入与输出，以及哪些条件必须在计算时检查。
数据字段见[数据说明](data.md)，市场公式和交易规则见[A 股](a-share.md)与[加密资产](crypto.md)文档。
文中的“产物”指已经保存的数据表、模型、预测、账本或统计结果；“原子发布”指全部写入和验证完成后，才让新产物成为可读取的正式结果。

## 研究设计与计算流程

研究配置明确输入、参数、时间窗、操作顺序、输出位置和重算范围。
每个操作完成一项计算，并检查所需数据和时间条件。来源准备与数据组装之后，
模型拟合（fit）、预测（predict）、评价与选型（evaluate/score/select）、
模型解释（explain）、校准（calibrate）、回测（backtest）、统计（statistics）和绘图（plot）分别调用。

相同输入可在新位置重新计算；正式产物不可变。调用者负责选择适用输入并确定重算范围。

## Python 与 CLI

公开 Python 函数放在负责该项计算的模块中。命令行接口（CLI）只负责严格解析 JSON，再调用同一个函数。

- `sources.prepare.prepare_source(config)`：指定原始源与新规范表位置
- `markets.prepare.prepare(config)`：指定已准备表或原生源，生成一个市场数据表
- `research.datasets.assembler.assemble(config)`：明确表、因子、标签和 feature_recipe
- `research.models.production.fit(config)`：一次真实拟合及只追加的试验记录；选择后的最终重新拟合仍用该函数
- `research.predictions.runner.predict(config)`：读取保存模型，按保存列顺序做新预测；`artifacts.outputs.prediction.read_predictions(path)` / `iter_predictions(path)` 只读已有预测
- `research.models.explanations.explain(config)`：明确冻结模型、解释方法及样本，保存独立解释数值
- `research.models.trial_selection.score(config)` / `select(config)`：完整有序候选的成熟验证评分及明确规则选择
- `research.portfolios.production.calibrate(config)` / `backtest(config)`：A 股监督校准与实际账户计算
- `markets.implementations.crypto.portfolio.calibrate_maker(config)` / `backtest_taker(config)` / `backtest_maker(config)`：各自独立数学和事件时钟
- `research.evaluations.runner.evaluate(config)`：显式信号、标签、时间窗和成熟截止评估
- `research.statistics_production.model_statistics(config)`：显式模型与预测集合统计
- `research.statistics_production.factor_statistics(config)`：显式因子与标签统计
- `research.portfolios.diagnostics.portfolio_statistics(config)` / `crypto_statistics(config)`：显式账本和比较集合
- `reports.plots.plot(config)`：已算数值到新图片

各阶段的 config 使用 JSON 值，包括路径字符串和时间窗口对象；底层 Python 存储 API
还可直接接收 Path、DataSpec、TimeWindow。复杂选择、窗口、风险、执行与候选设置均按严格 JSON 解析。
每个字段只从一个来源取值，不合并目录配置（profile）、环境变量或 CLI 覆盖值；省略字段采用默认值时，也记录解析后的实际值。
未知字段、重复 JSON 键、非法类型、非有限数、空的必要列、重复成员和非法窗口会在解析时直接报错。
完整 parameter_candidates 与基础 hyperparameters 不能同时声明。

CLI 用非零退出码区分非法请求（2）、执行失败（1）和必需输入缺失（3）。
结果中的 UNDEFINED 表示未定义，PARTIAL 表示只有部分结果可确认，NOT_APPLICABLE 表示不适用。
这些状态保留各项计算自己的含义，不再合并为一套统一的研究状态。
数据质量问题只影响必要域，其他独立研究可继续；无法合法计算的结果如实失败，不能造数。

## 数据与计算的职责划分

来源模块统一处理格式、列投影、单位和来源记录。
读取模块解码所选文件与列；计算模块检查公式、信息可用时点、标签成熟、采样与配对范围。
写入模块检查结构定义、跨批次主键和覆盖关系，通过后原子发布。
无需逐层重读同一批输入，但新增连接、域和账本关系必须真实检查。

拟合使用声明训练窗口内的全部合法样本，A 股与加密资产一致：先按真实可用时点、
标签成熟条件及所选输入的缺失规则确定资格。同一时点的完整截面与样本权重含义在计算中保持不变。
拟合按声明窗口逐窗读取，不扫描窗口间隙；窗口按实际时间边界有序且互不重叠，
纯日期结束界包含当日全天。精确时间/资产主键由读取器唯一核验；更宽的源主键
仍须由拟合模块核验时间/资产轴唯一性。

训练、选型评价与事后评价是窗口的用途，不是样本的永久身份。滚动向前研究（walk-forward）每轮明确
拟合窗口、决策截止、预测窗口及标签成熟截止；早期预测样本在以后标签成熟后可进入拟合。
样本外解释取决于实际训练与选择过程，窗口用途随实验记录保存。
缩放参数、排名方向/权重和监督校准只用允许的历史估计，之后冻结。
规则固定的当期截面裁剪、中性化、标准化（zscore）与排名（rank），在完整且当时符合 eligible 的截面上计算，
不能按物理数据块分开，也不能改成历史训练截面。
标签不能插补；派生目标成熟时钟先规范化为真实时间，再取参与标签的最晚可用时点。
任何参与标签的时钟未知，该依赖截面的派生成熟时间也未知；其他合法截面仍可计算。预测不等待未来标签。
A 股当前 wd 价格收益标签保留固定会话的经济开盘端点；复权调整来源依赖当日收盘，
普通 forward-return 的 `available_at` 因此为退出会话 Asia/Shanghai 15:00（现代 UTC 07:00）。
ON/ID 的 pre-entry、ID、ON/endpoint 分别在 t+1、t+h、t+h+1 会话收盘达到可用门槛。
经济开盘事件仍为 09:30；此 EOD 日频研究约定不等同于已核实供应商实际发布时点。

全局选择组 G 使用所声明的完整验证历史；季度选择组 Q 只用决策前已成熟的历史。选型只使用本次明确提供的验证指标。
A 股 `backtest.selection_mode` 默认 `causal`；显式 `retrospective` 与 `selection` 路径
用于终局选择对应的历史原始预测曲线。拟合截止仍须早于每个预测窗口；回顾曲线披露真实选择时点，
查询及统计保留其描述性用途，探索性诊断与独立样本外证据分别解释。
失败或指标未定义的候选仍须保留在候选集合中。有定义的成绩即使为负，也优于无法定义的成绩；
全部成绩未定义时不产生胜者。只有有定义的指标相等时，才按预先声明的顺序选择。
最终重新拟合保存真实 fit_windows/cutoff，离散窗口之间的空档不填平。
预测、评估和回测核实际拟合截止、标签成熟及必要校准时点，不要求预先登记未来窗口。

`research-rosters/` 保存因子、模型和窗口等实验设计参考，运行参数由各次操作明确给出。
算法能力与数学默认值以对应实现为准。

## 明确路径与发布

每次操作都明确指定输入路径。原生元数据记录实际输入、参数和随机种子、列顺序、窗口用途、
必要资格、成员及输出范围，不另加跨阶段包装，也不按软件摘要或结构哈希查找缓存。
执行记录保存实际代码与环境；工作区有修改时，需保留具体差异，dirty 标记本身只能说明存在修改。

一个模型目录保存 `predictor.pkl` 与 `model.json`；`model.json` 保存实际模型元数据、
`facts` 和 `trial_id`；试验记录独立保存实验过程。`research.models.persisted.load_model(path)`
只加载可信本地模型并核自身完成状态及必要拟合事实，不依赖外部试验记录日志，不触发训练；
不得加载不可信 pickle。
PRED 的 `prediction.parquet` 保存键及 `prediction_score` / `prediction_rank_score`，
标签与成熟列在评分/评估时从明确数据输入读取，不重开 PRED 的历史特征输入。
EVAL 按当前输入实际键与保存预测配对，使用当前资格与标签成熟域；不以历史模型输入重算预测资格，
缺预测或缺成熟标签的行不计入对应配对样本，空共同域保留未定义成绩。显式请求的因子/特征仍须提供。
预测 `source_column` 不得与本次评估实际消费的输入列重名；未消费的同名输入列不受此限制。
score 按实际配对键记录当前成熟标签域、缺预测/缺标签行数及共同样本数；空共同域保留未定义成绩。
score/select 各写自己的 JSON；
预测元数据保存后续使用必需的拟合与信号事实；评价、统计、回测读取已有预测时不加载 predictor。
使用方核实际需要的选型、校准时点及产物成员。

产物写入完成后原子发布，临时目录保持未完成状态；新输出拒绝覆盖已有产物。
失败和中断保留真实试验记录；只尝试过（attempted）不能补写成成功。明确复用已完成片段时，必须核对其实际研究范围，
不接受暂存（staging）或失败片段，已有试验记录不可改写。

普通读取支持指定文件成员、列、年份集合、日期/时间窗口及有限字段条件，保持顺序及数据类型。
文件发现前将输入选择与本次计算所需窗口取交集，未选年份不扫描；离散窗口各自读行，不填补空档。
数学回看、标签成熟和完整会话轴属于必要读取范围。日期结束日包括全天，精确时间区间闭合，
有时区时刻规范为 UTC；不按运行机器时区解释无时区字段。裸 Parquet 必须提供本次所需的列角色、单位和可用时点依据。
已明确声明的输入、模型、评价 market_id 必须相容；不从名字或路径猜市场，也不要求原本缺失的市场元数据。
跨市场迁移目前没有独立声明操作，不能静默把 A 股输入发布成加密资产模型或评价事实。
支持列只用于检查，不自动进入模型 X。结构定义中已声明的规范特征标志列，即使被单独选择，
仍自动读取其声明的底层结构列；普通外部列名的前缀本身不建立这些依赖。
日频闭区间的结束日含全天，纳秒时间保精度；加密资产观察覆盖[start,stop)与流量(t−100ms,t]各自保留。
缩输出不缩数学回看、成熟端点或完整截面。
时序准备使用完整声明 PANEL 键/生命周期轴确定真实会话，文件、年份、行筛选排除的报价保持未知，不能压紧交易时钟。
最终只发布选中 PANEL 信号键与输出窗口的交集，ON/ID、普通标签、执行许可和滚动因子采用同一规则。
完整轴只额外读取键和上市生命周期，不用未选价格补值。市场模型保留完整声明市场域：
被选择排除的成员不是已知不合格成员，当前市场收益及下一会话依赖的前日市值权重按未知处理，
已有滚动状态在后续完整窗口恢复；真实休市仍按市场生命周期处理。

原生 Binance/Tardis 来源的清单摘要描述输入，读取核验实际使用成员的结构与研究所需事实；
前缀游标关闭时释放资源。
输入产物不可变，同次计算不得并发覆盖已选输入。
真实解码失败、路径不合规则、成员缺失，或本次使用的数据违反计算约定时，操作仍须失败。关闭所有所属资源，并保留最初的异常。
来源接纳、传输验收和显式比较各按实际目的保留证据。
隐式读取原生数据时，复用已打开 footer 的原始行数核对所选物理分区；缺片或未声明的
非空分区不能静默变成少样本。显式 files 子集不要求凑齐全分区，未选年份不检查。
缺失 part 在同一物理分区内的具体时间未知时，该分区保守拒绝；可显式选择完好成员隔离。

## 执行、资金与统计

市场会话、滚动窗口、候选计算和账户推进支持一次调用内批量处理。
性能优化优先复用必要读取，并成批执行数值计算。
Tardis保全原源集合、顺序、单位、档深和重建状态，临时缓冲在该次实际计算结束及时释放；
未证等价前不裁历史前缀。

平均成交额（ADV）仍要求本市场连续20个已知观察，持仓核算保留上市生命周期和精确的权益单位。
缺少成交价时不能生成交易或费用。普通漏报价时，已有持仓只能使用同一生命周期内的可信报价暂估，并披露依据；不能凭估值制造现金。
冻结持仓仍占用风险和预算。金额有定义不代表比例也有定义：净资产（NAV）为零时，相关比例保留 UNDEFINED，费用和损益（PnL）直接读取账本。
加密资产的资金费预测与实际结算分别处理，真实缺口不补零，独立账户段不拼接净值或夏普比率（Sharpe）。

统计保留固定候选集合、完整区间、真实有效数量和未定义原因，不删除难以计算的成员来获得显著结果。
探索性选型的推断限制以实际研究事实声明。DSR/FDR只覆盖本次声明集合，不代表全部人工探索校正。
Fama–MacBeth统一采用浮点OLS/WLS，保留可识别性、样本权重及退化统计的未定义状态。

## 展示与检查

HTTP 接口只读，访问范围限定在绑定的项目根目录内；查询不读取原始数据。
图片读取已保存的计算结果，报告据此解释研究发现。
未定义留空、真实断段不连线；负权益不能截断；抽样图不能重算正式指标。
通用序列图在同一坐标轴共享显示缩放与单位，全空序列仍保留真实日期或类别轴，
缺失说明合并展示，不画假零数据。
分组保留原始身份，缺失组与同名字面字符串分别展示。
Matplotlib与中文字体只在绘图时加载，缺字体明确报错。

测试按实际规则组织，用最小样本和独立期望值检查公式与边界；不同故障机制分别保留。
直接 API、原子发布、原生回读及下游使用保留必要的真实链路，重复场景合并到同一规则测试。
主键、枚举、整数单位、列序与精确时间坐标按其离散约定比较；金额、收益、统计估计及数值解
按经济量纲、算法误差和容差比较，不将独立浮点计算的逐位一致作为通用准入。
同一持久化值及其缺失掩码无损往返；普通金融量纲下可分辨的权益、排名和样本变化仍须保留。
数值测试不承担整个浮点表示范围的金融运算保证。
验证包括相关行为测试、格式和静态检查、回归测试与代码审查；实际执行范围随变更记录，真实数据回放单独记录。

## 数据准备的显式选择

`prepare` 必填 `market_id, data_id, inputs, time_window, output_root`。
`inputs` 将本次使用的数据标识映射到路径；直接读取来源归档时，还需提供
`source` 的实际 `root` 与 `archive_paths`；来源种类由被选择的原生清单解释。
Bybit/OKX 规范化来源另用 `source={root, archives}`，不套用原生事件归档字段。
仅支持对应计算确实使用的 `parameters`、`factor_columns`、`base_panel`。
财报 PIT 的因子选择缩小必需源集合，未使用的参数直接拒绝。

`assemble` 必填 `market_id, dataset_id, inputs, time_window, output_root`；
可明确选择 `factor_columns, label_columns, feature_recipe, base_input_data_id`。
原生清单的 `inputs` 保留本次输入路径及显式 `files/years/time_window/row_filters/columns`
等选择；省略的选择器不额外限域。`parameters.input_columns` 记录实际使用列（含必要依赖），
输入级时间窗口与总体 `time_window` 取交集，不建立下游身份绑定或自动重算。
A 股的 feature 处理配方不自动训练变换；未标准化的派生特征保留实际选中源列的单位，
源单位未知则继续未知。加密资产的 `sparse_input_data_ids` 可明确选择非基表输入，
包括标签；缺失标签保留 NULL，依赖标签的训练或评价各自筛选合法样本，基表仍须完整。
标签成熟时刻和辅助信息可用时刻保留为真实上下文，不进入模型输入 X。

模型选择的 `score` 配置明确列出完整 `validation_windows`；该字段表示本次选型评价窗口，
不永久定义样本身份；标签只读取所选离散窗与本次评分窗的交集，不检验未使用空档。`select` 明确 `refit_windows` 与 `refit_cutoff`；最终拟合只使用这些
显式窗口内截至拟合截止已成熟的样本，允许加入之前未使用的新日期，不自动填平离散窗间空档。
模型与选型不声明 `test_window`。预测直接使用调用者选择的未来窗口，包含开放结束窗口；
实际预测开始必须晚于拟合截止，后续评价、回测不重新接纳模型的训练域。

因子和模型统计的 `dataset` 直接指向实际数据；原生输入读取自身 `spec.json`，
裸 Parquet 额外给 `input_spec`（与模型输入相同的 DataSpec 字段）。不要求内置 dataset ID。
`evaluation.factors` 明确选择统计列，`primary_label` 指定标签；自定义成熟列优先复用输入 DataSpec 的
`label_availability_columns`，已有显式声明须与输入研究所需事实一致。主键、资格、成熟及加权统计所需列
由统计模块加入读取，未选因子不进入计算。

## 并行与数值验收

Huber 可显式设置 `model.huber_target_scale` 为正有限倍数，默认 `1` 保持原拟合。
非默认值仅支持 `huber_regression`，用于小量纲目标的数值条件研究：拟合前将标签乘 `s`，
将 `alpha` 除以 `s`；拟合后将系数、截距和残差尺度除以 `s`，恢复原 `alpha`。
Huber 数据项对标签、系数、截距和尺度一次齐次，因此变换后的目标为原目标的 `s` 倍；
预测、解释、标签单位及保存模型参数仍使用原经济单位。原生模型事实记录该倍数，
模型状态保存对应标记，回读核对二者；已有默认模型无需补写字段。
该研究参数不改变样本、权重、特征缩放或预测期限，不自动选择倍数或重试失败拟合。
底层求解器仍采用自身初值、停止条件及固定正尺度下界；换回原单位后的数值下界随 `s` 改变，
所以代数等价不保证相同数值解或解决尺度退化。收敛警告仍保留为拟合失败，
研究应另核对目标值、梯度、残差尺度和跨环境稳定性，不能仅凭拟合成功声称优化可靠。

支持并行的模型通过已有 `hyperparameters.n_jobs` 控制；未指定时使用 `-1`，交给模型库自动并行。
显式合法值原样传递，不按本机物理核、亲和或配额拒绝、截断；负值、`None` 与 `0` 的含义遵循各模型库，
随机森林不接受 `0`。元数据保存传入模型库的线程参数，实际线程使用量由运行测量获得；
线程配置差异不作为模型读取的研究适用条件，算法超参数仍须一致。
NumPy/BLAS/OpenMP 尊重运行环境与用户配置，拟合不强制单线程。
独立候选和时间折可分别运行；任务并发与模型、BLAS/OpenMP、Arrow 的线程数统一分配，
避免每层各自使用全部核。单账户事件链、市场共同状态和完整日期截面不能按物理年份任意拆开。

预测使用模型实际支持的线程设置，不为浮点累计逐位一致强制随机森林串行。
并行加法可能有舍入差；测试按求和误差界与任务量纲验证。
固定种子不代表不同并行汇总必然逐位相同；离散样本、参数、列序和可用时点不得随执行方式改变。
IC、EWMA 协方差、中性化及标签校准复用稳定的向量化汇总。
排序先保留输入的顺序、并列与缺失，再以秩参与浮点计算；连续估计沿用浮点运算。
组合风险只将矩阵表示及二次型计算舍入界内的轻微负值归零，真实负风险仍拒绝。

性能比较固定输入、任务量、研究参数和随机种子，分别记录内核与端到端墙钟、吞吐及真实扫描量。
比较前后保持候选数量、回看窗口、样本资格和缺失规则一致，提速倍数以代表性实测为准。
合成测试与真实研究的耗时、完成范围分别记录。


### 特征选择与缺失值

`assemble` 的 `label_columns=[]` 生成无标签预测输入，不要求标签产物。
`feature_transform` 可选择 `clip`（`none`、`mad`、`quantile_1_99`）、
`industry_neutralize`、`size_neutralize`、`center`、`scale` 与 `impute_missing`。
`size_column` 默认 `log_total_market_cap`，可显式选择 `log_float_market_cap`；
依赖投影、计算和持久化语义均使用同一选择，关闭规模中性化不要求辅助规模列。
具名处理配方只提供默认组合，元数据保存解析后的实际参数。执行顺序固定为裁剪、
中性化、中心化、总体标准差缩放；关闭的步骤不要求其支持列。
中性化保持等权复制样本前后的投影结果，残差按实际运算误差区分舍入与有效信号。

辅助规模、行业、资格字段由所选操作推导，仅作为工作列，不擅自加入模型 X。
规模因子不对自己做规模回归。中心化保留原量纲，除标准差后为无量纲。
中心化加缩放沿用常量输出 0 的既定约定；仅缩放遇零方差为未定义，保留缺失和诊断，
不偷偷采用单位缩放。仅中心化的单观测结果为 0。

`impute_missing=True` 保留具名处理配方的技术零填补；只在截面变换可定义时填普通原始缺失，
`feature_observed_*=0` 记录其不是实际观测。零不总是均值，也不能直接参与实际观测统计。
设为 False 保留 NaN 和指示列；标签始终不填补。输入角色、模型有序 X 与输出选择是不同集合。
缺失/观测伴随列由完整声明结构定义解析并补入物理投影，按二值字段校验。
普通缺失为(1,0)，结构不可用为(0,0)，已观察有效为(0,1)；模型只核实际使用列族，并要求至少一个原始输入已观察。
声明的伴随列缺失或无效仍拒绝；
外部普通 feature_x 未声明伴随关系时不凭名字索取 feature_observed_x。

`fit` 与 `score` 的 `label_unit` 可从输入 `column_units` 复用；缺声明时才需明确提供，
两处同时声明必须一致。模型保存实际成熟列及最终训练样本的最大成熟时刻，核其不晚于拟合截止。
通用相关和期间回归不为单位未知另设准入；结果保留单位未知的说明，风险溢价解释需明确经济单位。
模型 facts 必须保存 input_units，只包含实际使用的有序 X 中已声明单位；空对象表示均未知。
预测在调用估计器前拒绝这些列的显式单位冲突，不自动换算，不重开训练输入。
任一侧未知仍是未知；未使用列的单位、文件路径和 data_id 不形成模型身份绑定。


## 选择计算与数值产物

`prepare.factor_columns` 选择实际计算的因子，`prepare.label_columns` 选择标签值列；
标签的前瞻期限由已有定义推导，对应可用时间列自动输出。省略选择沿用该表的默认集合。
依赖表、列、回看及前瞻由所选计算决定，不为未选标签读满最长前瞻，不为现金比率强求市值表。
输入的 `years`、`time_window`、`files` 与数学窗口取交集；显式裁掉必要历史时结果按真实缺失处理，
不绕过调用者的选择。年分区读取在发现文件前裁剪年份，仍验证实际选择路径。

EVAL 按实际预测键与标签键配对；预测声明窗可以只覆盖评估窗的一部分，无预测日期只影响对应信号的观察数。
因子统计的 RankIC-only 读取 metrics；分层和覆盖成员仅在所选分析实际依赖时读取。
因子统计可分别选择 RankIC、Fama–MacBeth；组合统计可分别选择绩效、基准、归因、容量、
Sharpe 推断、CSCV 和组间比较。未选分析不读取其专用输入，也不生成占位表。
Fama–MacBeth 等权与市值加权分别使用其合法样本域；不可用市值仅影响依赖它的加权结果，保留各自观测数和未定义原因。
这些数值结果默认作为探索性研究输出；完整研究是否保留了独立最终评价，由研究设计与真实
决策记录判断，不能凭 `test` 或 `global` 名称自动授予统计资格。

PRED 只保存下游实际需要的处理配方、训练域、成熟/拟合/选择截止及必要标定，不复制缩放器、
特征重要性或依赖包版本。拟合状态属于模型产物。已有预测可直接用于下游；不要求模型文件仍在。

`model_statistics.evaluation.baseline` 可选 `zero_prediction`（默认）或 `training_mean`。
每次真实拟合将最终合法训练标签按实际训练权重估计的 `training_target_mean` 冻结在模型事实中，
随 PRED 传递；显式选择训练均值时，每个期间/家族使用其对应冻结值，缺少该事实则明确失败。
评价标签不参与估计基准，统计不重读训练源；解析后的基准及权重口径随描述指标元数据保存。

模型统计的 `model_losses` 分析同时保存逐日预测描述表，字段与单位见
[模型预测描述指标](data.md#模型预测描述指标)。Head 20% 先由全部有限预测固定成员并纳入阈值并列，
再核标签成熟；分组评价也先按预测分组。最高组没有可评价标签时保留零观察组，
不把下一组替作最高组计算 spread。描述指标不依赖 IC 是否有定义。

`model_losses` 中的 `loss` 是各家族自身有效证券上的负RankIC；共同观察数不表示该列已在共同证券上重新排名。
直接相减要求同日有效证券身份一致。覆盖不同时，显式请求 `model_comparison`，同时提供双方预测并用
`comparison_model_id` 指定基准；计算先取同日双方预测和成熟标签均有限的证券交集，再分别重新排名。
差值方向为挑战方案RankIC减基准RankIC，完整输入日期轴及缺失推断限制继续保留。

多重检验主方案为 BY，BH 为辅助；模型统计自助法默认 2000 次，显式 repetitions 覆盖原值并存入元数据。
HAC、自助法、模型联合检验、FMB 和分层推断不把已知缺失日期压紧：
实际输入日期轴上缺少有效统计量时推断记 `incomplete_session_clock`，有效值的描述均值仍保留。
完全未出现在输入中的交易日仍依赖上游完整市场日历事实，市场交易日历与普通工作日索引分开处理。

## 共同因子域、分层与持久化评价复用

`evaluate` 的 `sample_scope` 明确选择 `own` 或 `common`，默认 `own`。
共同样本与分层功能只适用于 A 股横截面（cross_sectional）评价中符合 eligible 的因子/特征信号；预测信号和加密资产不使用这套截面分层约定。
`comparison_inputs` 只描述真实输入选择器与其参与共同域的因子/特征列，不用研究昵称证明配置相同。
共同域逐标签核对精确资产/日期、资格、真实 observed 值及各自成熟时点；只比较最终共同域内同目标、同单位的标签。
独立浮点标签使用相对容差 `rtol=1e-12, atol=0` 核对，保留标签量纲和零值边界。
共同域中的真实目标、单位、缺失或成熟时点变化仍按对应约定检查。
整数标签在成熟掩码、缺键对齐后仍保留精确整数表示，不能转浮点而吞掉一个整数单位的差异。
特征值不重做中性化，先在焦点方案的完整截面上变换信号，再施加共同样本掩码；对照方案缺少日期时，保留共同样本为空的诊断。

可选 `strata` 明确主标签及行业、规模、流动性或预测年龄分层。
行业按已声明的分类标准与代码分组；未声明标准的输入沿用代码域，已声明但缺失的标准归入未知层。
先在焦点 eligible 且主标签成熟的总体定义层，再施加共同域，不能在收缩后的样本重新排名。
缺失层与真实行业字符串分开；可定位的非法数值只使相应分类未知，另存 invalid 计数。
年龄字面闭区间之间的小数未分配不等于真正缺失。
日评价、覆盖和分层由同一个 EVAL 写入器发布；按成员读取与流式读取使用同一套含义校验。
该 A 股日评价路径支持可选正整数 `workers`（默认 1）；调用方显式指定进程数，多日同时计算，父进程按原日期顺序归并及写入。每批日期数等于进程数，输入扫描与汇总仍保持流式；工作进程失败时保留原异常并关闭进程池，不发布不完整产物。
持久化日表按 timestamp 非递减；同一天可跨批次延续，但主键不能重复。键校验只保留当前日期，避免全历史键集合。
预测年龄读取 median_forecast_age_days_fy1（原列单位 days），须选用该原始 factor 或声明由它生成的 feature，
freshness 选择 90 或 180 天；闭区间为 0–7、8–30、31–60、61–90，
180 天配置另含 91–180。7.5 等区间间隙单列未分配计数，负值、无穷及超范围年龄为非法分类，NaN 才计真正缺失。

`factor_statistics(evaluation_inputs=[...])` 显式使用已发布 EVAL 日表并可切窗，不重读 DATASET、重算 IC 或触发 FMB。
`dataset` 计算路径与持久化输入路径互斥；FMB 由实际数据计算模块承担。
`stratified_ic` 使用显式声明的 HAC/FDR 参数，常用研究配方为 lag=20、BY、alpha=0.05。
校正家族一次覆盖本次明确输入的 scope、信号、层和 IC/RankIC，统一校正该集合，历史上未纳入的探索不在校正范围内。
预定家族中未定义的假设仍参与校正数量，内部以 p=1 占位；对外 p/q 保持 NULL 及原原因。
`defined_hypothesis_count` 仅披露可定义项数，不用它缩小校正家族。
汇总 own/common 两份结果时，核对它们声明的信号、目标、单位、成熟截止与分层设置，并分别确认本次选中窗口位于各自已发布范围内。
统计只汇总所选日表；两份 EVAL 的外围窗口可以不同。

## 比较结果前需要核对的条件

G/Q 模型比较通过 `global_predictions` 显式选择参照 PRED 列表；两组预测在本次明确的 dataset/标签与成熟规则上共同评价。
逐日期、家族在真实共同资产键域计算 RankIC 差异，复用标签扫描；不拼接可能来自不同实际标签的旧聚合损失。
缺参照家族或可配对观察只影响对应比较，独立评价继续保留。参照选择时点未知时，结果用于描述差异，不作独立样本外推断。
RankIC 比较以本次共同标签为目标，不要求两组模型原训练目标或其单位相同；需要数值尺度可比的 MSE 等指标仍遵守各自目标与单位规则。
组合的组间比较同时核原生 candidate.selection_group 与固定构造事实，不能由候选 ID 前缀授予研究角色；
相同预测或相同现金轨迹本身不是错误。

## 任意组合的可选基准比较

`portfolio_statistics` 与 `crypto_statistics` 省略 `analyses` 时均只计算 `performance`。
其他分析必须显式选择；未选分析不读取其专用输入。组合构造的 `benchmark_id` 只属于构造与持仓归因，
通用比较使用独立的 `comparison_benchmarks`，简单组合、增强组合和加密资产均可选多个参考序列。
可选分析使用以下长表：

- `benchmark_comparison`：配对区间收益、收益差、财富比与相对风险指标。
- `market_exposure`：完整配对时间轴上的市场回归，显式 `hac_lag`、`confidence`、`minimum_observations`。
- `regime_comparison`：按显式 `threshold` 区分参考市场区间收益，输出描述性统计。
- `control_comparison`：读取明确提供的已有对照收益，不自动重跑回测。

每个参考项声明 `reference_id`、`input`、`representation`、`value_column`。研究所需事实 `valuation_currency`、
`timestamp_basis`、`return_basis`、`cost_basis` 必须可解析得到，可显式声明或复用输入 DataSpec/manifest.parameters 的事实；冲突拒绝。`endpoint_level` 使用 `timestamp_column`；
`interval_simple_return` 使用 `start_column`、`end_column`，收益单位由数据规格或显式 `return_unit` 给出。
`timestamp_basis` 为 trading_day_open/trading_day_close/utc；`return_basis` 为 price/gross_total_return/net_total_return/strategy_net/constant_cash；
`cost_basis` 为 frictionless/execution_costs/zero_cash；区间收益单位为 decimal 或 percent。
trading_day_open/close 的时间列保存午夜会话日期标签，名称说明估值相位；utc 才保存真实 UTC 时刻，不能混用 ON/ID 经济事件或标签可用时刻。
文件、年份、时间及行列筛选复用原输入选择器；混合多个未筛选序列不能当作一条指数。
`comparison_controls` 使用同一描述结构，明确策略净收益与执行成本口径。

两个市场共用 `portfolio_benchmark_intervals`、`portfolio_benchmark_metrics`、
`portfolio_market_exposure`、`portfolio_regime_comparison` 长表，保存候选、执行模式、独立分段、研究轮次与参考序列的身份，分别对应 candidate、execution、episode、fold、reference。
区间两端时钟、币种和收益口径必须相容。价格指数和全收益指数分别声明，不暗中替代或换汇。
局部缺点、非正点位及无穷值使依赖区间未知，计划区间、缺失与观测计数一并保留。
缺某个参考源只影响其比较，已有组合绩效继续保留。

市场回归仅在完整合格配对日轴上计算系数与推断，缺口时保留原因及计数，不把有缺口的日期压紧后套 HAC。
A 股通过现有 `inputs.calendar` 明确提供交易会话，每个收益区间必须连接相邻会话；仅账本端点相接不能证明日频，周末与节假日按该日历处理。未提供日历或跨过交易会话时，保留区间、财富和环境描述，日年化及相关推断标记 `incomplete_daily_axis`。
市场暴露的 `status/reason` 描述点估计，`inference_status/inference_reason` 单独描述系数推断；已识别零截距与零 beta 不因 t/p 未定义而抹去。有限标准误与置信区间按实际计算保留，未定义 t/p 不进入有效 BY 假设计数；相关系数及 R² 的推断为 `NOT_APPLICABLE`。
中心化、按列缩放和系数数值零解析与 Fama–MacBeth 共用数学实现；HAC 与 White/日期聚类推断保持各自语义。
HAC 完整协方差矩阵还原至原收益坐标（包含截距与斜率交叉项）；操作数尺度内的精确仿射拟合保留点估计、零 SE 和退化区间，
t/p 为 UNDEFINED，原因 `zero_residual_variance`，不以全局绝对阈值删除可解析的小系数或噪声。
回归一次以本次候选、参考、独立分段、研究轮次的截距与 beta 为 BY 校正家族，保存计划/有效假设数。
A 股比较按 252 日年化；加密资产比较默认 365 日、至少 2 个完整 UTC 日，可由现有 statistics 字段覆盖并保存实际参数。
未提供无风险收益时截距叫 `market_return_intercept`；请求无风险序列但缺失时不能退回零利率，constant_cash 仅表示现金路径，不提供无风险收益序列。
按当期实现的市场收益划分环境属于 `ex_post_descriptive`，预先选阈值也不使它成为当期可交易信号。
这些结果帮助区分市场暴露和相对表现，不单凭正收益或显著截距证明因子因果有效。
只有收益序列的对照用于描述表现差异；股票池、成本和调仓规则的一致性需另行核对。

## 随机种子约定

`model.random_seed` 省略时在配置解析中规范化为 42；显式合法种子原样传入后端，
不自动按模型、折或季度重派生。解释及随机统计的根种子同样在各自配置解析中默认 42；
显式 null 不等于省略。实际解析种子随参数/模型产物保存，不修改进程全局随机状态。
解释日期、行、背景通过 `derive_seed` 按用途独立派生；置换按 axis、group、repeat
及 segment 样本键派生，不包含 model_id、worker 身份或执行顺序。
匹配比较要求相同根种子、数据域、样本资格和抽样/置换配置；不能仅凭相同随机种子声称支持集相同。
跨环境数值结果按对应算法的误差约定验证。

## 冻结模型解释

Python `research.models.explanations.explain(config)` 与 CLI `qrp explain --config ...` 共享入口。
解释读取现有 MODEL，不拟合、不改缩放器、不重新选择模型。输出独立 EXPLAIN，预测、组合和统计都不依赖它。
`explain` 可选依赖组提供 SHAP；只选模型原生重要性时不需要 SHAP 或输入数据。

必需字段是 `model`、`output`、非空 `methods`。只有 `native_importance` 时不传数据选项。
贡献方法一次选择一个：`affine`、`linear_shap`、`rank`、`native_tree`、`tree_shap_path`、`tree_shap_interventional`；
还可同时选择 `native_importance`、`permutation`。方法须与真实模型匹配，不能用另一种解释静默替代。
有逐行贡献或置换时另传 `inputs`、有限 `window`、`sample_role`、`selection`、`output_space`。
`selection` 明确 `max_rows`、`max_dates`，可选 `asset_ids`；`root_seed` 省略时为 42，显式值覆盖默认。
`max_dates=null` 表示全窗口。
先保留选中时间的完整截面，再抽展示/评分行，rank 不在展示子集重新排名。
解释输入不支持 `row_filters`，资产展示筛选通过 `selection.asset_ids`，避免无意改动 rank 截面。

`output_space` 为 `model_output`、`raw_margin` 或 `calibrated_label`，按真实模型能力使用。
非恒等目标变换的原生树贡献只解释 raw margin，不把它标成收益。
`linear_shap`、`tree_shap_interventional` 必须明确 `background`：inputs、window、max_rows；
background 的 `root_seed` 省略时为 42，显式值覆盖默认。
背景逐行受真实拟合窗口、精确拟合截止和训练资产域约束，并标明所选历史参考分布及其覆盖范围。
抽样使用有界 reservoir；其余方法不接收未使用的背景选项。

贡献表保存 timestamp、asset_id、feature、input_value、contribution；input_value 是逐源列保真的可空数值文本，缺失保存为 null，不参与贡献计算；旧浮点 input_value 产物需重新解释生成。
预测表保存基值、真实输出、预测分数、
加和残差与容差及逐行状态。加和检验同时考虑运算误差与输出精度；普通舍入保留解释，
贡献不可表示或严重抵消导致精度丢失时标 UNDEFINED 与原因，有效预测仍保留。
summary 给出有符号/绝对均值、绝对占比、排序与覆盖，另可按 month/quarter 汇总。
贡献汇总先逐日取截面均值，再对日期等权，不按展示行数跨日期加权。
原生重要性表记录真实方法和单位，不能统一叫 SHAP，更不能自动叫样本外有效性。未缩放线性模型的原始值系数单位为目标/输入单位，明确排除缺失指示器贡献；完整逐行贡献可选 affine，不能把原始系数视作跨量纲可比的完整影响。

置换配置明确 `metrics`（ic/rankic/mse）、成熟 `cutoff`、`groups`、`repeats`、`axis`；
`root_seed` 省略时为 42，显式值覆盖默认。
`within_timestamp` 在日期截面内置换；`temporal_blocks` 明确 episode_column、block_size、step_seconds，
要求单资产连续窗口、max_dates=null，只支持 ic/mse，不跨独立分段或缺口重排。
同组列一起置换；原始与置换后的评分键保持一致。置换形成全输入缺失时，该干预对应期间局部未定义并记录原因；只在全部组/重复与基线共同可定义的完整期间聚合，不分别删行改变比较队列，独立解释方法仍可发布。基线或非全缺行的意外非有限预测仍报错。rank 的 MSE 只在 calibrated_label 尺度计算。
模型选型、统计和置换解释复用目标定义/单位比较；定义从训练实际使用的 spec/label_semantics 冻结，随 MODEL→PRED 保存。
未知或不一致只使平方损失未定义，合法 IC/RankIC 继续计算；score 的候选 `mse_reason` 与解释行 `reason` 保存准确原因。
定义只包含源标签、transform、clip 和所选源标签语义，不绑定路径、hash 或无关 spec 字段。
within_timestamp 的 MSE 先逐日算均值，再日期等权；temporal_blocks 保持整条成熟时间序列一个评分 period。
重复结果与均值/标准差均保存，未成熟标签不参与，测试集结果不反馈为自动调参。

`explanation_summary`、`explanation_waterfall` 只使用 EXPLAIN，支持 PNG/SVG/PDF 与中文字体。
前者选择贡献绝对均值或 native_importance、period 和 top_n；后者精确选择 timestamp、asset_id，
保留有符号其余贡献、存储残差与真实输出。无定义解释展示原因，不画假零。

### 输入实例与已有特征复用

`assemble.inputs` 的键是本次输入实例名，可以为同一原生 `data_id` 的不同目录分别命名。
原生 `data_id` 及研究声明保留，不要求为横向拼接改写原件身份。`base_input_data_id`
指本次基表实例，`sparse_input_data_ids` 同样引用实例名。相同输出列仍要求唯一生成方；
公共行情、资格、行业等辅助列通过
输入 `columns` 投影选定权威来源，不能按输入顺序覆盖。唯一可用依赖仍可自动补入。

`feature_columns` 选择已经物化的特征，省略时取输入实际投影中的 FEATURE 列；
可用 `factor_columns=[]` 不选原始因子，这些已有列不重新变换。
已声明的观测/缺失伴随列、单位、标签成熟事实与原变换说明随复用保留，
再次组装或评价不能把它们当作未经处理的原始值。省略配方及变换参数时，
已有完整目标组输出的因子直接复用，仅为未处理的新增因子生成默认特征；
显式配方/参数要求的新生成特征与复用列同名时明确失败。
组装的基表及每个辅助输入各自只扫描一次选定文件。辅助输入的物理分区可按资产排列，
因此先物化本次已投影、已裁窗的辅助行，再按真实时点稳定排序并对齐完整基表截面；
内存占用与本次选定的辅助输入行相关，不为每个基表块重扫辅助年度文件。
基表仍沿用完整截面迭代器的时序校验。辅助排序不修改时间精度或主键。
strict/sparse 主键覆盖仍在整个请求窗口校验，
包含基表前、间隙及末尾的辅助多余键；失败或关闭时关闭所有输入迭代器。
解析后的输入实例、原生 data ID、实际使用列、filter/context、处理配方和目标列写入参数记录。
命名目录提供省略字段的默认值，实际解析结果随产物记录。

### 按所需成员读取解释与校准

`read_explanation(path, members=[...])` 只读取选定成员；省略时保持完整读取。
汇总图和原生重要性图（summary/native）不依赖未使用的贡献明细；瀑布图（waterfall）读取预测及贡献，仍核对键、
状态与加和关系。请求 predictions 或 contributions 会成对读取二者，不能借投影绕过该关系。
发布时仍验证完整解释产物。账本中的可选最终 alpha 校准仅在实际访问时读取；
净值图和基础绩效不依赖这个无关成员，账本现金、成交与权益勾稽保留。

`temporal_blocks.step_seconds` 用秒声明研究步长，例如 0.1 或 1.5；
连续性按原始时间精度检查，时间缺口划分为独立片段。
候选评分中不可表示的辅助 MSE 保存为未定义，合法 IC/RankIC 保留；这不改变
选型指标全未定义时不产生胜者。明确请求的解释 MSE 仍遵守其数值可定义约定。

所有已经明确时区的时刻都转换为 UTC，包括跨夏令时、具有不同时区偏移的输入。
无时区（naive）与有时区（aware）数据混用且未声明解释依据时，仍明确拒绝，不猜测机器时区。

### 模型统计的独立分析

`statistics-model.analyses` 可选 `model_losses`、`prediction_hac`、
`prediction_bootstrap`、`model_comparison`、`spa_reality_check`、
`stepm_superior_models`、`model_confidence_set`。省略时计算全部分析。
仅所选分析要求其专用参数和输入：损失表不要求比较基线或自助法；MCS 不因其它
比较方法而要求基线。模型比较采用 HAC 与自助法组合。
需要随机分析的模型统计配置将省略的 `root_seed` 规范化为 42，显式值覆盖默认；
非随机分析不因此要求随机参数。成对组间比较（paired group）另需自己的自助法参数，并使用其中声明的随机种子。

模型与组合 G/Q 比较将声明的 confidence 同时用于 HAC 和自助法区间。
所请求分析的 lag、自助法与置信度参数先按合法类型及范围验证，不因空数据或退化推断跳过。
仅请求 prediction_hac 时只计算该分析所需统计。

HAC 的 status/reason 与 bootstrap_status/bootstrap_reason 分开保存；某项推断未定义
不会删除另一个合法结果或真实描述均值。零观测的均值保持未定义。缺失日期保留在完整输入会话时钟中；
时间序列缺少任何日期的合法观测时，推断为 incomplete_session_clock，不能压紧缺口。
FDR、选型指标及正式研究门槛仍按实际研究约定判定。

省略 sample_scope 的 own 评价与显式 own 采用相同日事实路径。EVAL 生成时负责实际键、
共同域和成熟规则；STAT 复用时来源路径只作出处，祖先 DATASET 不再可用也能汇总。
调用者负责选择同一研究问题的 EVAL；STAT 不通过原始资产或标签内容身份替调用者选输入。
所选日表的精确主键、日期顺序、状态和必要计数仍由读取器和统计汇总模块校验。
已有特征继承的变换说明同样参与必要研究条件核验与预测年龄分层。

模型统计窗口完全没有输入观测时，明确报告 `statistics_model_observations_empty`，不发布空产物；
已有预测却缺输入覆盖时仍先报告覆盖不一致。有实际日期、但标签未成熟或估计未定义，
继续保留相应未定义结果，不能把“无输入”与“有输入但不可估计”混为一谈。
