# 因子想法在股票、日内与 ETF 中的实现

本文件说明同一机制如何使用不同观察频率；[假设清单](factor-hypotheses.md)维护机制范围，
[处理清单](../configs/factor-analysis-policy.csv)是逐列去极值、标准化及中性化的唯一配置。
目录注册与公式实现不代表数据齐全、计算完成或实证有效。计算状态以原生结果为准。

## 去重取决于实际评价域

- 相同输入、相同窗口、相同有效样本下，完全相同、仅反号或严格单调的表达只留一个代表。
  例如平均成交额保留 `avg_amount_20d`，删除对数入口；该原值还用于流动性分母。
  5日反转与跳过最近20日的中期动量表达不同机制，继续保留。
- 同一个股票截面统一乘正数，不改变排序、Pearson IC、RankIC或分组。
  此类宏观交互保留为条件模型或状态信息，不增加独立因子排名。
- 单 ETF 按交易日计算日内时序相关时，一天内不变的正日频背景乘数也不会改变排名。
  原始回撤与残差回撤分别乘同一日内过程时，在该评价域不重复计作两个独立发现。
  负乘数会翻转方向，零乘数会产生常数，未知乘数会减少样本，均不能当作新增预测机制。
- ETF 跨日时序中的状态随日期变化，可以改变排序，不能套用同日截面去重。
  按不同有效日期算出的相近 IC 不证明等价；剪尾产生并列或风险残差改变排序时，也不机械删除。
- 仅因相关性高不删除有独立含义的窗口或机制；不通过穷举交互扩张目录。

股票高频仍只消费已有面板；暂停扩盘不阻塞已有两天的因子计算。
缺日频风险、两融、行业、订单或发布时间，只限制实际依赖该字段的输出。
不把基金/指数上市前的回填价格当作当时已发布历史，不因不依赖的缺项停掉下游。

ETF证券级两融复用`financing_factors`的12个非股票流通市值／流通股数定义，
包括买入／偿还强度、余额变化、成交承载、净回补及价格条件压力。
决策输入保留真实上市交易日、信号会话与可用时点，分母使用本基金同观察日的成交额／份额成交量；
无该ETF的两融记录就保持未知。基金份额不冒充股票自由流通股，
不提供缺少真实分母的股票流通市值／流通股数比率。
逐列清单明确保留原始时序，不使用未来阈值剪尾或四基金截面中性化。

## 本次补齐的定义与 owner

`price_volume/definitions.py` 与 `calculations.py` 共同拥有日频价量公式。
`etf_price_volume_factors` 是 `daily_quotes.py` 中的薄资产适配入口，消费原生
`etf_daily_panel` 的完整信号会话轴，把计算结果放回原来的实际盘前决策时点；
不会新增股票上市资格门槛，也不会重新定义价量算子。按列选择只有实际输入可支持的定义，
支持的字段由原生目录派生，包含路径统计；不生成伪造换手率或市值。

| 输出 | 定义、窗口及时间 |
|---|---|
| `breakout_activity_divergence_20d/60d` | 当前复权收盘超出此前窗口收盘高/低点的有符号对数幅度 × max(log(此前平均成交额/当前成交额),0)。区间内为0；实际突破缺少必要成交数据为NULL。用于研究弱成交支持的突破，不预设反转方向 |
| `price_flow_divergence_30s/300s` | 窗口对数收益 × max(−sign(收益)×窗口有符号成交量/总成交量,0)。价格上涨而供应商方向标记成交流向下为正，下跌而供应商方向标记成交流向上为负，方向一致为0；仅保留这一个有符号表达 |
| `price_up/down_acceleration_30s/300s` | 共用 `compute/dataframe/history.py::quadratic_log_trend`；尾随30/300秒、3秒网格、因果最近报价且年龄≤6秒，不跨连续段。二次对数价格曲率除网格对数收益RMS，只在端点斜率与曲率同方向时为正；平坦路径无定义。不是屏幕角度 |
| `prior_drawdown_x_activity_x_depth_recovery` | 已知此前20日原始回撤 × 10×volume(t−30,t]/volume(t−330,t−30] × 当前已观察的60秒深度恢复；不足历史或零基准为NULL |
| `prior_residual_drawdown_x_activity_x_depth_recovery` | 同上但背景换成共用风险模型20日加法残差路径回撤。只对股票截面作为不同暴露列，不在单ETF单日重复排名 |
| `index_group_positive_fraction_5d/20d` | 显式固定指数集合中，实际市场会话端点收益为正的指数比例；缺任一成员不改变分母 |
| `index_group_leader_gap_5d/20d` | 同一集合最强指数收益减其余指数等权平均收益；与个股/行业广度区分 |

固定指数研究选择见[唯一配置](../configs/linked-markets/index-group.json)：沪深300、中证500、中证1000。
它们覆盖互补规模区间，但收益仍可能高度相关，不能按三个独立市场样本推断。
各指数在首次发布前的回填值被屏蔽，窗口端点也必须在已发布区间。
指数收盘可用时间采用本仓库明确的信号日15:00:01上海时间假设，盘前决策消费上一会话；
不是供应商历史实际发布日志。发布日期分别由[深交所](https://www.szse.cn/aboutus/trends/news/t20110119_517266.html)、
[中证500资料](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000905factsheet.pdf)、
[中证1000资料](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000852factsheet.pdf)核对。

`prior_ownership_crowding_x_intraday_liquidity_stress`只对股票截面使用此前已披露的持有基金HHI乘当时流动性紧张指标；不将订单大小解释为真实机构身份。

日内有符号成交流沿用来源方向标记，其主动买卖方身份尚未独立验证，不冒称严格主动流。

## 文献如何约束实现

- [Blume、Easley、O'Hara，JF 1994](https://doi.org/10.1111/j.1540-6261.1994.tb04424.x)
  讨论成交量提供的价格之外信息；[Lo、Mamaysky、Wang，JF 2000](https://doi.org/10.1111/0022-1082.00265)
  将技术形态系统化检验。这里的突破量价衰减是按用户假设定义的候选，未冒称两文原始因子。
- [Cont、Kukanov、Stoikov，JFEconometrics 2014](https://arxiv.org/abs/1011.6402)
  区分订单流不平衡、深度和价格冲击；不能用成交量替代委托流，也不能把简单响应比称因果冲击。
- [Heston、Korajczyk、Sadka，JF 2010](https://arxiv.org/abs/1005.3535)
  区分短时流动性反转与同刻跨日延续。保留不同窗口的研究意义；两天股票历史不能支撑40日同刻估计。
- [Moskowitz、Ooi、Pedersen，JFE 2012](https://fairmodel.econ.yale.edu/ec439/mosk.pdf)
  研究资产自身的时序趋势；不能把跨资产截面筛选原样作为ETF自身时序信号。
- [Greenwood、Thesmar，JFE 2011](https://www.hbs.edu/ris/Publication%20Files/Stock%20Price%20Fragility_eac0d3cb-4174-4a4f-af7d-610ff4e9de48.pdf)
  区分持仓集中和共同流动性冲击；成交拥挤代理不等于真实所有权脆弱性。
- [Ben-David、Franzoni、Moussawi，JF 2018](https://doi.org/10.1111/jofi.12727)
  研究ETF套利和标的波动联系；PCF/份额压力有机制依据，但不能由份额变化识别每笔真实买卖。

本轮先检验因素，不增加预测模型、组合或回测。原始、预处理、风险残差的不同结果保留实际处理记录；
六类相关均按原生定义计算，并复用同一评估记录汇总全历史和近期窗口。
