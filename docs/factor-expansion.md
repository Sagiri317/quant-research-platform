# 量价、持仓与跨市场因子扩展

本文件说明研究定义和原生输入，计算完成情况以实际产物为准。因子标签、输入依赖和窗口由原生目录提供；去极值、标准化和中性化选择统一保存在 `configs/factor-analysis-policy.csv`。本文不把目录注册当作实证完成，也不把预测相关性当作可交易利润。

## 展示名称与计算标识

因子同时保留中文含义名、原有英文计算标识和来源数字编号。中文名称及窗口、宏观变换、交互与处理阶段的组合规则统一由 `research/factors/names.py` 负责；日频与高频研究目录在注册时绑定，目录 API 和结果表从同一 owner 读取，不各建翻译表。`feature_` 显示为“处理后”，`feature_pre_neutral_` 显示为“中性化前”，原始字段完整保留。

`alpha101_054` 的中文主名称为“开收比五次方加权负收盘位置”，即 `-((C-L)/(H-L))*(O/C)^5`；`alpha191_046` 为“3／6／12／24日均线综合价格比”，即 `(MA3+MA6+MA12+MA24)/(4*C)`。编号仍作为原始出处和计算标识，不能从名称推断已证实反转或动量效应。纯展示名更新不改变公式、方向、窗口、可用时点或持久化字段，无需因改名重算数值。

有效 IC／RankIC 次数要按评价轴解释：日频股票截面通常是有效交易日数，每日另有参与相关计算的股票数；多空分别在各自分位组内计算，信号恒定或配对不足的日期不计入。单资产全区间时序相关可能只有一次估计，其配对观测数另存于原生 `metrics.n_obs`，不能把一次估计误读成只有一个价格样本。多空组内相关不是多空组合收益相关或收益回测。

## 去重与处理

保留 `reversal_20d`，删除与它严格反号的普通 `momentum_20d`；保留剔除最近20日的60/120/252日动量。普通 `momentum_60d` 仍供可选对照和已有宏观交互使用。`risk_residual_momentum_20d` 是风险回归后的收益路径，不能与普通动量等同删除。SKEW 保留原指数及已有历史变换，删除仅仿射换算的独立偏度标签。

股票连续重尾指标采用 MAD、同日截面标准化及行业五风格残差作为对照；事件、占比和相关状态保留零值与端点，通常不剪尾。原始结果始终单独评估。市场或风格共同状态按日期计一次，不对复制到股票上的常数做截面 IC；ETF 各自做时序分析，不强制使用四基金截面标准化或股票风险模型。高频股票只能使用当时已知的行业和上一日风险暴露。缺少某个风险暴露只限制相应残差结果。

风格组合用上一会话已知的 A 股范围和暴露选股，随后聚合原生 `period_return`。是否当日成交不决定已持有股票的收益是否已知：停牌等情形已经提供的有限估值收益继续使用。真正未知的收益仍使该日相应固定篮子收益未知，不补零、不按事后可观察性换股或重配权重；20／60会话窗口仍要求至少75%的有效日。

ETF被动流量压力保留来源声明的PCF成分数量。只有全部类型的成分行数、唯一成分数与声明数量相符，且头部及全部成分已经公开，才能将清单外股票的该篮子贡献记为零；清单内数量或单位未知仍为未知。完整PCF只代表申赎清单完整，不代表基金全部实际持仓。行业压力在已知个股贡献上求和，保留原始和MAD去极值、截面标准化结果，不做会消除行业共同信号的行业中性化。

## 日频定义

| 类别 | 实现口径 |
|---|---|
| 失败突破/跌破 | 20/60/252个会话的先前高低点；日内越界而收盘返回区间，或首次收盘突破后3/5会话内首次严格收回原边界。边界在突破时冻结，等于边界的回踩不算失败；事件在失败已经发生时才可用。 |
| 突破路径 | 有符号持续会话数、相对首次冻结边界的后续涨跌幅、成交活跃度；返回区间后结束。递归事件读取自身真实完整历史，不能在输出切片边界重置。 |
| 加速 | 对20/60个会话的对数价格回归常数、时间及时间平方；用末端斜率识别上涨/下跌，以曲率除以同期对数收益均方根。零波动未定义。另用最近6个完整月平均收益减前6个月平均收益，当前未结束月份不进入。 |
| 行业补涨/补跌 | 1/5/20会话中，同行业剔除自身等权收益与本股收益之差，分别要求行业上涨/下跌并保留正向缺口；另保留有符号相对收益。使用当期分类标准和代码，不从未来补分类。 |
| 广度与集中 | 市值权重收益与广度变化之差、3/5年历史广度分位数、正收益贡献 HHI、实际涨跌停参与率。小市值且高换手股票成交占比只称投机活跃代理。 |
| 风格轮动 | 根据上一会话可见的规模、市场 Beta、跳近期动量、残差波动及 Amihud 分组，计算高低五分位组合收益差，累加20/60会话；另计算两组风格收益的60会话相关。 |
| 风险后行业共振 | 自身及剔除自身行业的风险残差收益相关，20/60会话；不能由原始收益相关直接改名得到。 |
| 两融压力 | 融券数量/流通股、融券数量/20日平均成交股数、偿还数量/成交数量、净回补1/5会话；逼空代理结合可覆盖天数、已发生净归还、正收益，去杠杆代理结合融资余额下降和负收益。绝对名义余额不直接跨年代比较。 |

假突破和二次对数趋势加速是依据用户描述明确算子的研究假设，没有冒称唯一经典公式。六个月加速差的依据是 [Yale 对 Xiong 与 Ibbotson 研究的说明](https://insights.som.yale.edu/insights/should-investors-look-for-stocks-with-momentum)；本实现保留连续差值，不复制其中的阈值分组组合。不同窗口有研究含义，未按高相关性直接删除。

## 跨市场与基金

`linked_market_factors` 与 `fund_flow_factors` 通过显式 `decision_panel` 输入消费实际需要的列。源表均为结构化 `raw` 经原生接入得到的版本化事实；下载、PDF/网页提取在仓库外完成，仓库不保存解析网页或下载金融数据的业务爬虫。

- 期货：实际最近未到期合约与相应现货指数之比减一，远近合约之比减一；升贴水年化使用交易所实际到期日与剩余日历天数。持仓量跨上市合约汇总，变化使用比例；换月集中度为合约持仓 HHI。基差变化不把不同近月合约的换月跳变当作同合约冲击。对冲交互需要同一基准的显式 `hedging_beta`，不拿全A Beta 替代。
- 经济配对：调用方明确 `pair_assets`，按20/60会话计算相对收益、以前期 Beta 对当前收益残差化及价差历史标准分。ETF 配对使用有实际分红拆分依据的复权价格，不用原始未复权价拼接。
- 美国传导：FINRA 场外短售量/总成交量、5个观测日变化及756个观测日历史分位数；该数据是短售活动，不能称空头存量。美国行业 ETF 收益使用调整收盘价；行业映射键为 `分类标准:行业代码`，也可显式设置 `asset_us_tickers`。自身 Beta 用已完成收益和对应信号日开盘前已知的美国冲击配对，再控制同期市场收益；不把今天隔夜冲击与昨天本股收益错配。
- 指数扩散：只使用公告已经可见且已生效的真实成分变化；官方权重缺失只限制权重集中度。不会用当前成分回填历史。
- ETF 份额：1/5/20个实际会话端点变化及相对前20会话变化分布的惊喜值。份额变化不等于现金流。被动买卖压力逐日使用该日真实 PCF 成分股数量与最小申赎份额单位，5日结果要求五个历史篮子，不把最新篮子套到过去五天。金条克数不会当成股票股数。
- 溢价：市场收盘价与净值必须属于同一经济日，取二者均已可用的最新配对。一级二级背离也先按同一经济日配对份额变化与已观察成交不平衡，再按发布时点对齐。
- 中国基金：组合资产和现金比例使用同一报告内的共同有效样本。半年/年度申赎份额除以期初份额及对应月份数，得到月均份额流率；不从名义 AUM 增长推断流入。不同份额类别只在原报告明确披露的类别中汇总一次；组合资产不因 A/C 类重复相加。赎回股票压力使用流量期间开始前已披露的持仓。完整股票表与明确无股票报告通过 `public_fund_holdings_reports` 替换同一经济组合的旧快照，较早报告的迟到修订不覆盖较新报告期；缺少股票行本身不能证明零仓。A股压力只消费 `CN_MAINLAND` 的明确证券身份，港股和未知市场不按六位代码混入。
- 机构持仓：完整报告替换原持仓集合。13F 的原始报告、补充新增持仓及重述分别处理；最新报告无目标持仓会清除上一期目标仓位。HHI 及行业配置描述已公开申报样本，不代表所有最终投资者。N-PORT 按完整基金元数据选择至少3个月前的报告，即使该报告已无目标 ETF，也不能沿用更早持仓；仅使用普通股数单位的多头份额，不混入卖空、期权或互换。三个月净现金申赎除以前期净资产，与前期披露的美元持仓值加权，再乘披露持仓 HHI，作为拥挤流量压力代理。

资金压力的经济机制参考 [Coval 与 Stafford](https://www.nber.org/papers/w11357) 和 [Lou](https://academic.oup.com/rfs/article-abstract/25/12/3457/1594242)，实际数据频率和公开时点下的上述代理不声称逐项复刻原论文。N-PORT 持仓 `value` 按 [SEC Form N-PORT C.2.c](https://www.sec.gov/files/formn-port.pdf) 已是美元；币种字段是投资计价币种，不能再次汇率换算。

## 高频定义

`hft_factors` 扩展自己的开盘、恢复及波动路径；`hft_research_factors` 消费已有 `hft_panel`，不会创建新截面面板。

| 类别 | 口径 |
|---|---|
| 开盘 | 09:30附近6秒内有起点报价；在首个达到5/15/30分钟的观察时点冻结收益、路径效率和累计成交不平衡。相对活动量比较此前20个明确会话的同一开盘窗口。 |
| 尾盘 | 以历史实际连续交易结束时间为准，累计最后15分钟，比较过去20个会话相同时刻的累计活动；不把所有历史日期统一当作14:57或15:00结束。 |
| 恢复 | 冲击时点为当前时点之前30/60/300秒；价差至少为其此前60秒均值两倍，或深度至少减半。恢复幅度相对冲击与正常状态之差，已知无冲击为零，所需基线未知为未定义。 |
| 共振及补涨跌 | 真实同观察时间的同行业剔除自身收益/卖压/流动性压力，30/60/300秒；不把后来的同行报价带回当前时点。供应商异步时可能样本稀疏，需按实际有效观察数解释。 |
| 波动分解 | 观察到的对数收益上/下半方差、下半方差占比，30分钟与当日累计。BV 为 π/2 乘相邻绝对收益乘积和；至少需要一对有效相邻收益，不跨午休或隔夜做差分。微观结构噪声仍可能影响结果。 |
| 成交密集区 | 使用截至当前已发生的真实成交量，按固定20bp对数价格格累计1/5会话；POC距离、集中度、格内插值的现价上方比例和从POC向外累计70%的价值区宽度。5会话缺少任何必要历史日则未定义；不是完整账户成本分布。名义价格跨除权事件时须单独解释或排除该窗口。 |
| 挤压与去杠杆 | 上一日已知的融券可覆盖天数、净归还与正收益/买方流量相互作用；融资收缩与负收益/卖方流量相互作用。它们不能识别账户强平或主观回补意图。 |

BV 的理论来源为 [Barndorff-Nielsen 等](https://arxiv.org/abs/math/0503711)。这里使用有限观察样本的基础统计量，不宣称已完成无噪声跳跃检验。行业信息传播参考 [Hou 的论文](https://doi.org/10.1093/rfs/hhl013)，补涨补跌的事件门槛和窗口为本项目可执行变体。

## 输入缺口与评估

未知发布日期保留未知；显式假设的净值发布上界保留 `availability_basis`，不能写成真实历史时间戳。当前版本 Yahoo 调整价格含事后调整信息，须按当前版本研究解释；不同基金的前身不跨上市生命周期接续。零售借券费率、真实可借库存和账户平仓方向没有可验证数据时不补造。

`implied_minus_past_realized_variance_20d/60d` 要求同标的、匹配期限的年化隐含方差及相应过去收益波动率。逐合约 IV 或30日指标不能直接改名成该输入；缺少标的、期限、单位或发布时点时只保留该项未定义。美国 VIX 不替代A股标的隐含方差。

`etf_daily_panel` 可显式输入上交所 `public_option_risk`、`public_option_contracts`：按真实合约身份及已生效、已可见的元数据匹配行权价与到期日，每个到期选最接近平值且认购认沽均有正 IV 的行权价，平均两侧方差；按实际到期日以 `日数/365` 计算总方差，在包围目标期限的两个到期之间线性插值。目标期限事先固定为20/252、60/252年，避免依赖事后实现的未来交易日历；以真实合约到期日插值，不外推。使用同标的过去20/60会话收益样本方差乘252作比较。它是 ATM 隐含方差代理，不是方差互换复制或官方 iVIX。源零 IV 仍保存在原始/中间表，仅该计算排除。合约调整保留真实份额单位，不恒置10000。当前官方每日收盘口径外推到历史日末的可用上界是显式假设，不能称逐日实测首发时刻；该数据目前覆盖510300/510500，其余标的保持缺口。

股票日频主要按同日截面计算；单个ETF或市场共同状态使用 `correlation_clock="observation"` 的时序相关。每个因子保留有符号总体 IC/RankIC、最高20%多头及最低20%空头样本内 IC/RankIC，空头仍是原始因子与收益方向，不人为取反。均值仅平均有效相关，报告有效样本数；常数和不足样本保持未定义。原始结果与处理后结果分开，效果由实际产物确定。

`market_state_factors` 将市场结构与风格的共同状态按信号会话对齐到一个明确的指数决策轴，不把同日复制到几千只股票的值当作几千份市场样本。宏观目录中的954项序列变换及11项共同状态可直接在该指数决策轴计算；其余154项股票交互与敏感度在股票决策面板计算。高频历史21会话只服务相对活动量基线，当日共振和恢复不会因同一输出批次包含基线而重复计算此前20天。
