# Archive

This directory stores frozen historical records.

Archived files are useful for tracing past decisions, rejected paths, implementation history, and old acceptance context. They are not current contract truth, current commands, current roadmap, or current implementation source of truth.

Current QRP truth sources are:

- root project docs such as `README.md`, `AGENTS.md`, `EVALUATION_INTERFACE.md`, and `PROJECT_STATUS.md`;
- schema registry and tests;
- `manifest.display`;
- `docs/code-map/`;
- `.codex/skills/quant-research-platform-maintenance/` references.

Do not update archived records to match current state unless a task explicitly asks for archive maintenance. Prefer updating active docs and leaving historical records frozen.
