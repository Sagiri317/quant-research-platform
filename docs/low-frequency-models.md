# 股票与 ETF 监督模型

股票和高频 ETF 分别预测、选参、交易和评价。股票在下一交易日开盘前 09:00 生成预测，目标从该日开盘到第五个后续交易日开盘，跨五个交易日，以当日合格股票截面标准分作为标签。开盘成交遇到涨跌停、停牌、无量或容量限制时，实际持仓与理论标签可能不同。每只 ETF 独立预测未来 30 秒中间价的小数收益，损益由成交、费用和持仓路径决定。[股票模型配置](../configs/run-quarterly-a-share.json) · [ETF 模型配置](../configs/high-frequency/run-sessions-etf.json)

## 因子与模型输入

个股模型优先取同一经济量经政策指定的去极值、标准化后、行业及风格中性化之前的表示，缺少该列时取原始计量。同一因子只选一列，保留规模、红利与低波动可能携带的收益信息。单因子研究仍可用中性化结果衡量剥离行业和风格后的贡献。每天对所有股票完全相同的市场状态，单独输入不能区分当天的股票，已定义的个股条件交互可提供区别。ETF 的标准化由各自训练历史决定。财务和分析师预期未纳入本轮政策。

四个模型共享每折用训练历史确定的代表。股票用每日截面秩估计冗余，ETF 用单只基金的历史观测。代表列在该折的验证、重拟合和预测中冻结，下一折在覆盖相近时优先延用上折代表。完整规则见[因子代表](factor-representatives.md)。

## 架构和候选参数

| 模型 | 股票 | 单只 ETF |
| --- | --- | --- |
| Lasso | 三档 L1 强度，检查非零系数数量与收敛 | 使用适配小数收益标签的三档 L1 强度 |
| XGBoost | 深度 3 或 4，较深候选加强叶权重惩罚 | 深度 3 或 4，平方误差，按成熟验证样本早停 |
| LSTM | 一层 64 单元，60 个交易日，输出前 dropout 0.1 | 一层 32 单元，20 或 60 个已知观测，午休和隔夜切断序列 |
| Transformer | 一层 64 维、4 个头、Pre-LN，60 个交易日 | 一层 32 维、4 个头、Pre-LN，20 或 60 个已知观测 |

股票神经网络允许用端点读取配置中指定的慢变量，序列编码器处理其余列。两种网络均在每个样本的最后一个真实时间步读取端点；填充不会变成新观测。ETF 配置全部使用序列列。Pre-LN 的层内归一化和编码器末端归一化一起使用。[Pre-LN 原论文](https://proceedings.mlr.press/v119/xiong20b.html)

## 研究设计与验证诊断

每个股票季度或 ETF 会话块重新拟合。股票选当时成熟的 120 个验证交易日，按每日截面 RankIC 比较同一家族的候选。ETF 以 60 个拟合会话起步、20 个验证会话，按日均 MSE 选参，预测随后的 20 个会话。模型家族始终分别产出预测，各折可以选择不同参数。训练插补和缩放只用拟合样本，XGBoost 保留原始缺失。股票标准分预测在完整可评分截面去均值，ETF 的小数收益保留原始幅度。[滚动研究](research.md#滚动选参与重拟合)

用训练和验证损失、RankIC、预测截面离散度、Lasso 非零数及早停位置判断问题。训练持续改善而验证恶化说明需要减小容量或提前停止。训练和验证同时停在常数基线附近时，先检查标签时点、有效列、插补和学习率，再考虑增加容量。按日聚合观察，密集盘口行和重叠五日标签不能视为独立样本。候选值是本轮配置的起点，实际收益和夏普比取决于冻结后的样本外预测及成交。

## 股票组合和 ETF 底仓

股票组合将已发布的模型分数与随后成熟的五日真实收益配对，配置使用最近至多 252 个已成熟的可用日期，至少 20 个，按日期等权估计共同收益及截面斜率，再换算为当次持有期收益。未累积足够成熟历史时保留已有账户状态。收益优先与风险调整共用同一成本和成交规则。均值方差目标最大化预期持有收益减去成本以及持有期方差惩罚，风险厌恶为零时只比较成本后收益。本轮单股上限 2%，允许留现金。组合不要求固定比例的大盘股或红利股。[组合配置](../configs/backtest-stock-weekly.json)

两种股票账户从同一份配置取预测、初始资金、费用、交易限制和单股上限。下面是收益优先账户的独立调用，从数据和结果所在的工作目录运行。风险调整账户直接使用配置中的参数。

```python
import json
from pathlib import Path

from quant_research_platform.research.portfolios.production import backtest

config = json.loads(Path("code/main/configs/backtest-stock-weekly.json").read_text())
config["candidate"].update(candidate_id="xgboost_net_return", risk_aversion=0, risk_style_columns=[])
del config["inputs"]["risk_context"]
config["output"] = "results/a_share/stock/weekly/utility/xgboost/net-return"
backtest(config)
```

ETF 一个账户只读一个模型的一组预测。初始半仓，14:50 起尽量回到最初份额。比较基准从相同现金和份额开始持有，日内增益取两本账本之差。未完成恢复的份额和隔夜价格影响继续入账。[ETF 账户](../configs/high-frequency/backtest-policy-etf.json)
