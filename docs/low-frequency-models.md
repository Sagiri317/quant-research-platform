# A股低频监督模型的设置依据

本协议以未来5个交易日收益的当日合格股票截面标准分为唯一目标，比较 Lasso、XGBoost、LSTM 和 Transformer。
执行配置以 [quarterly-a-share.json](../configs/quarterly-a-share.json) 为准；本页解释实际生效的设置及取舍，不另建配置副本。
已观察的旧20日研究结果保留原身份，见 [监督模型预测结果](../reports/监督模型预测结果.md)。
这里的选择是研究设计，不是已证实的5日效果提升。

## 判断依据与修改范围

旧20日共同11季中，四模型在673日、1,466,797个相同成熟配对上的日等权 MSE 分别约为
1.0104、1.0029、1.1435、1.1424，均未优于零分数；正的 IC 不等于预测幅度校准良好。
Lasso 的原正则上界 `.01` 选中8/11季。小 LSTM 选中8/11季，大 Transformer 选中8/11季，
深度6的树选中7/11季。候选同时改变多个参数，这些次数不能识别单一宽度、窗口或学习率的因果作用。
两类神经网络选中模型的最佳验证轮数主要为1，支持先放慢更新，不支持未经验证就加深网络。
224期 Lasso 诊断中只有50期属于股票，其余174期是另一任务的ETF；不能用ETF效果选股票参数。

相对旧20日方案，5日方案保留四家族及每季3／4／2／2、共11个候选，做五项参数调整：

1. Lasso 用 `.03` 替换 `.0001`，保留 `.01` 与 `.001`，向历史经常触及的较强正则方向扩一档。
2. 两类神经网络小候选学习率 `.001→.0003`，大候选 `.0003→.0001`；降低更新幅度，不改变样本或早停预算。
3. 股票 Transformer 使用 `independent_layer_initialization=true`，每层经同一原生构造器独立初始化。
   PyTorch 官方明确说明默认编码器把同一初始层复制到各深度，并建议独立初始化。
   该调整不改变架构、参数量或候选数；一层候选没有层间复制问题。
   已有ETF协议省略该参数，保持默认 `false`；已保存模型仍加载其实际权重。
   此处依据是初始化规范，并未证明预测收益改善。[PyTorch TransformerEncoder](https://docs.pytorch.org/docs/2.12/generated/torch.nn.TransformerEncoder.html)

4. 股票 LSTM 设置 `input_gate_xavier_initialization=true`，仅第一层的四个输入门权重各用原生 Xavier uniform；循环权重、偏置、后续层和输出层仍按原生构造初始化。旧ETF默认false。真实宽输入的初始门饱和诊断支持控制输入尺度，不等于预测效果已改善。
5. XGBoost用深8、L2为100替换深3、L2为100，保留深3、L2为10及深6两档正则。检验更高容量是否改善验证误差，不增加候选总数。

验证集支持的诊断和本轮处理如下；依据为[全部历史候选](../reports/data/stock-model-20d-validation.csv)，不是随后测试成绩选参。

| 验证证据（旧20日、11季） | 可以判断的内容 | 本轮处理 |
|---|---|---|
| 小／大LSTM平均验证MSE为1.150046／1.201150，分别10／11季和11／11季高于1；22个候选中21个第1轮最佳 | 问题在验证阶段已经存在；扩大候选没有改善平均误差，但学习率、窗口及容量同时变化，不能单独归因于深度 | 优先降低学习率、修正宽输入初始化；保留小模型对照，不继续加深加宽或延长耐心 |
| 小／大Transformer平均验证MSE为1.112342／1.072903，各10／11季高于1；大候选赢8季 | 较大候选有相对优势，但幅度预测仍弱；不是所有网络都应一律缩小 | 保留两档容量、较低学习率和独立层初始化；暂不同时更换激活、归一化与损失 |
| XGBoost四组平均验证MSE为0.976827—0.978385，深6赢7季 | 当前树模型具备更好的验证误差；尚不能证明深6仍然欠拟合 | 保留浅树及深6正则对照，加入一个强L2的深8候选 |
| 旧Lasso最强alpha选中8季；新五日已有10季中`.03/.01/.001`分别选中5／2／3季 | 正则上档有实际用途，不能只按输入数机械缩放alpha | 保留三档；去重前后维数仅减少2.67%，不据此再改容量 |

未来每季仍只用当时验证期选择候选，再用成熟训练加验证历史重新拟合、冻结预测下一季度。
MSE考察幅度与偏移，IC/RankIC考察排序；排序存在而MSE较差不能直接证明只是过拟合。
旧候选逐轮验证曲线不完整，也没有梯度范数，尚不足以区分梯度异常、均值漂移和噪声拟合。
当前不增加预测校准层、梯度裁剪或新架构来掩盖这个证据缺口；新协议须按同一验证口径检验上述调整。
新拟合会把已计算的神经网络逐epoch训练／验证曲线保存在候选的`learning_curve`，
XGBoost逐轮原生验证指标保存在`early_stopping.validation_metrics`；不增加训练集评估或额外拟合。
曲线随候选选择事实进入最终模型记录，便于在验证阶段发现问题。NN训练曲线仍是在线epoch损失，
不是每轮冻结后重新计算的训练误差；历史未保存的曲线不会因代码更新补齐。

## 共有样本、目标与验证

| 项目 | 实际设置 | 决定及理由 |
|---|---|---|
| 目标 | `forward_return_5d` → `model_target`；`date_zscore`、`target_clip=none`；单位为标准分 | 保留明确的五日单目标，预测期限不随20／60观察窗口改变。真实尾部不裁剪，也不填补标签 |
| 特征声明 | 四家族声明去重后全部可算输入，现为1069个原始表示和207个处理后表示，共1276列；每个原始因子只取一种表示 | 35个近重复项直接删除原生实现，采用[经典代表](factor-representatives.md)；其余全部保留。该取舍来自已观察数据，历史回测不称为未触碰的盲测；不增加运行期PCA或聚类筛选 |
| 特征来源 | 量价、行业/五风格、两融、PCF被动流、公募持仓与赎回、期货套保、宏观及跨境暴露 | 不使用 Choice 财务或分析师预期；`financing_*` 是两融而非财务报表因子，公募持仓/赎回来自基金报告。通用财务适配能力的存在不代表本协议消费它 |
| 已有特征处理 | 逐列复用原生产者记录的剪尾、行业/五风格残差及标准化；原始表示保留其经济定义。旧335列协议的208个处理后输入曾分为129列MAD加风险残差、77列只做风险残差、2列MAD加标准化 | 复用原生产者元数据；不在模型复核中重新剪尾或中性化。具体处理含义见 [因子处理](factor-treatment.md) |
| 资格与成熟 | `sample_filter_mode=eligible`；沿用数据集排除ST/PT、至少252个上市会话的资格；输入至少一列可观察；标签及其完整依赖在拟合截止前成熟 | 保留。缺失或未成熟标签不变成零；不以当前存活股票回填历史股票池。252是当前模型池资格，不改写各因子自己的回看要求 |
| 全缺失/常量列 | 仅在当时合法训练样本中判断并移除；相同输入域的家族复用同一选择 | 保留，不用全历史缺失率或验证标签筛列。旧11季保留285—297列，不代表新5日一定相同 |
| 部分缺失 | Lasso/NN用当期合法训练样本的逐列中位数填补；XGBoost保留原生NaN分支；全缺失行不预测 | 保留，不新增缺失指示列。每列取合法训练样本行上的无权中位数；均值/方差另按训练权重，预测冻结复用训练估计 |
| 样本权重 | 每日总质量相同、日内股票等权：`N/(D*n_d)`；无半衰期 | 保留，避免上市公司数量增长给后期天然更高训练权重；无按市值、波动率或收益大小额外加权 |
| 模型缩放 | Lasso/NN在合法训练样本中拟合加权总体均值/标准差；XGBoost `training_scaling=false` | 保留。树分裂不需要统一量纲；L1惩罚与梯度更新需要可比尺度。与上游截面处理职责不同，不使用验证/预测估计量 |
| 开始与推进 | 训练起点2014-01-01，扩窗；按季度冻结并预测下一季度，观察截止2026-10-30 | 保留，不改成固定长度训练窗或衰减；历史数据增加并不保证信号稳定，但当前没有识别出更优截断点 |
| 历史验证 | 截至预测开始前最近20个标签已成熟的信号会话；候选训练在验证开始前结束，并再次按其拟合截止筛成熟标签 | 保留实际时间顺序，成熟间隙按标签事实产生，不用随机CV或机械删除5行替代；20会话相互相关，不能当20个独立实验 |
| 候选排序 | 同一验证共同域的日等权MSE，较小者胜；相等时保留配置次序 | 保留与目标匹配的误差标尺；不按随后预测成绩选候选，也不把相关性与MSE混成一个分数 |
| 最终重新拟合 | 重新从头拟合当时全部合法历史（包括已成熟验证标签）；NN/XGB复用选中候选最佳轮数 | 保留。重新拟合的过程loss、冻结最终模型的训练误差、当时验证误差、随后预测误差分别报告 |
| 评价 | 截面IC/RankIC、MSE/RMSE/MAE及零预测基线；日等权；`top_quantile=.2` | 保留；零基线评估校准和误差，不代表可交易组合；分位诊断不是扣费后收益 |
| 不确定性 | 原生HAC带宽20、bootstrap块长20 | 保留既有统计协议。标签变为5日不证明最优相关修正长度也应为5；不把未经配对检验的均值差说成显著胜出 |

旧11个验证窗另做了只读输入核对，见 [逐窗样本与缺失摘要](../reports/data/stock-model-validation-inputs.csv)。
按各折最终输入列计算，缺失单元格占23.40%—35.89%；部分在训练中可用的列在某验证窗全空。
因此原生缺失或训练中位数策略有实际用途，完整案例删除会改变样本域；该摘要不是全2014—2026年缺失率。

当前早停的 NN 验证MSE和 XGBoost 验证RMSE按行等权，候选排序按日等权。
旧11窗内每日日样本质量相对等权在0.97618—1.01697之间；对固定模型的非负平方误差，
这也界定了两种加权MSE的相对差异，但不界定改变早停后模型的差异。
当前保留这个已记录的内外层目标差别；没有保存历史完整CV曲线，不能声称把早停改成日等权就会改变或改善最佳点。
20个成熟会话是贴近当时市场的局部选择，代价是选参方差；扩大至60日、重复CV或更多随机种子会改变协议和计算量，
本次没有相应证据指定一个“更优”窗口。全段5日回放已受到旧结果启发，不称为从研究设计到选参都未见数据的独立确认。

## Lasso：求解与正则

| 项目 | 实际设置 | 决定及理由 |
|---|---|---|
| 损失/惩罚 | 加权平方损失加 `alpha*||β||₁`；平方损失含 `1/(2N)` | 保留可解释的稀疏线性基线。L1不等于NN的AdamW，也不把α与XGBoost叶权重惩罚直接比较 |
| α候选 | `.03,.01,.001`；基础值`.01` | 调整上界，依据旧`.01`选中8/11；没有证据强行压成单一α |
| 截距/符号 | `fit_intercept=true`；默认 `positive=false` | 保留自由截距和双向暴露，不强制所有因子同向或输出非负 |
| 求解器 | 坐标下降，`selection=cyclic` | 保留；种子不改变循环列顺序。随机坐标可能更快，但未在本真实矩阵验证收益 |
| 收敛 | `tol=1e-4`、`max_iter=null`；按原生对偶间隙继续同一求解至收敛 | 保留，1000步起的内部迭代块不是研究上限；不靠放宽容差、提前停止减少任务 |
| 预计算/复制 | `precompute=true`；默认 `copy_X=true` | 保留。按块累加加权中心化Gram/Xy，调用同一原生坐标下降内核；各alpha复用充分统计，不组装全量scaled X。1276列的float64 Gram约12.4MiB |
| 热启动 | 外部默认 `warm_start=false`；无上限求解在同次拟合内部临时延续状态 | 保留，不跨季度或跨α借用历史模型做额外隐含初始化 |
| 随机性 | `random_seed=42`→`random_state=42` | 保留统一种子；cyclic实际不依赖随机列选择 |

目标函数与停止条件核对 [scikit-learn Lasso](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html)。
相关特征使Lasso可能选择其中一列；这不自动要求改成Elastic Net/Ridge。
加入L2混合会改变本家族定义并引入新的强度比例，旧结果尚未比较这些比例，因此保留Lasso基线，不把系数选择解释为稳定的因果发现。

## XGBoost：树、采样与优化

以下隐式值同时核对已安装 XGBoost 3.2.0 和旧模型原生 `save_config()`；不以网页最新版替代实际后端。
参数含义见 [XGBoost官方参数文档](https://xgboost.readthedocs.io/en/release_3.2.0/parameter.html)。

| 项目 | 实际设置 | 决定及理由 |
|---|---|---|
| 任务/输出 | `objective=reg:squarederror`；一个连续输出；默认验证指标 `rmse` | 保留。RMSE与同权重MSE排序相同；不换Huber、分位数、排名损失或多任务目标 |
| 树类型 | 默认 `gbtree`，`num_parallel_tree=1`、`process_type=default` | 保留梯度提升；不改随机森林或DART，不增加随机失活调参 |
| 深度/叶权重 | `(max_depth,reg_lambda)=(3,10)/(6,10)/(6,100)/(8,100)`四组合 | 旧20日深6选中7/11季；用原深3、λ100的候选名额比较深8、λ100，保留浅树和两档深6，不增加候选总数。较深树配较强L2，检验复杂交互是否有增量，不预判深8更好 |
| 子节点门槛 | `min_child_weight=100` | 保留较强的小叶约束；平方损失下是加权Hessian质量门槛，存在日权重时不能说恰好100只股票 |
| 其他正则 | `reg_alpha=0`、`gamma=0`、`max_delta_step=0` | 保留现有L2、深度、叶质量与采样控制；没有独立证据再加入L1、分裂惩罚或叶更新限幅 |
| 采样 | `subsample=.8`、`colsample_bytree=.8`；默认 `sampling_method=uniform`；`colsample_bylevel=colsample_bynode=1` | 保留行/列随机采样；不叠加每层每节点抽样以免过度压低候选信息 |
| 生长/直方图 | `tree_method=hist`、`device=cuda`、`max_bin=256`；默认 `grow_policy=depthwise`、`max_leaves=0` | 保留成熟的GPU直方图实现与深度控制；`max_leaves=0`不取消已设深度上限。加密bin未有真实误差证据 |
| 学习率 | `.03` | 保留现有小步长；旧选中轮数1—647，未出现固定轮数截断，不能仅据神经网络问题一起下调树学习率 |
| 树数/早停 | `n_estimators=null`、耐心50；严格改善验证RMSE，原生callback保存最佳树前缀 | 保留无总轮数上限；重新拟合使用 `best_iteration+1`，不是耐心结束后的全部树 |
| 初始分数 | 默认 `boost_from_average=1`、自动估计 `base_score` | 保留训练目标估计截距，不从验证期估计；旧首折保存值约−3.54e−11，并非人工设0.5 |
| 约束/类别 | 默认无单调与交互约束；`enable_categorical=false`；`missing=NaN` | 保留连续数值输入及原生缺失分支；分类阈值、类别编码等非活动选项不参与此模型 |
| 线程/随机性 | `n_jobs=16`、种子42；默认 `seed_per_iteration=false` | 保留计算设置，不因线程改变研究样本；GPU浮点归约不承诺跨硬件逐位相同 |

原生稀疏处理和加权直方图已有算法依据：[Chen与Guestrin，2016](https://arxiv.org/abs/1603.02754)。
这说明不必为缺失改成插补后的另一份树输入，不说明XGBoost必胜所有神经网络。

## 神经网络：完整结构和实际默认

两种候选的序列长度、宽度和层数分别为 `(20,64,1)`、`(60,128,2)`。
这些是最大历史观察数，不是20／60日预测期限。每条股票序列止于当前预测时点，只消费已经可见的特征。
保留两种候选，是因为旧结果中两种容量都有胜出；深度、宽度和序列长度成组变化，不能据此说60日或128维单独更好。

| 项目 | LSTM实际设置 | Transformer实际设置 | 决定及理由 |
|---|---|---|---|
| 输入/输出 | 当折冻结的输入列经训练缩放；最后一层最后有效隐藏状态→带偏置线性单输出 | 输入线性投影→可学习位置嵌入→编码器→最后有效位置→带偏置线性单输出 | 保留单目标，不加输出激活或把分数限制为正；预测目标是实数 |
| 内部激活 | 输入/遗忘/输出门sigmoid，候选状态与单元输出tanh | FFN默认ReLU，注意力softmax | 保留。GELU是合理替代，但原论文实验不能证明本股票目标上优于ReLU；LSTM改门激活会变为另一循环单元 |
| 深度/宽度 | 1×64或2×128；`bidirectional=false`、`proj_size=0`、`bias=true` | 1×64或2×128；4个头，每头16／32维；FFN宽度`2*hidden`即128／256 | 保留有限容量；不因“深度学习”名称再堆层。不将4倍FFN当必需规范 |
| 时间信息 | 单向LSTM，默认零初始隐藏/单元状态；每个历史片段独立开始 | 相对片段位置0…L−1的可学习Embedding；无额外CLS、日历嵌入或旋转位置编码 | 保留。输入已有多期限因子，不为了更长序列重复增加大网络 |
| 可见域/填充 | packed sequence忽略右侧填充，只取真实长度末端 | key padding mask屏蔽右侧填充；历史片段内部可双向注意，最终只预测片段末端 | 保留。片段内全部为已知历史，不需要因生成模型惯例而添加三角mask；不允许看到端点以后行 |
| 分组/断点 | 两者按asset及`listing_date`分组；全输入缺失处切断，短历史按实际长度使用 | 同左，`enable_nested_tensor=false` | 保留上市生命周期和断点，不跨重上市接序列，不用后续数据补足历史 |
| dropout | 小候选0；大候选.1，只在相邻LSTM层之间。没有input、recurrent-state、输出头dropout；单层即使设非零也被owner置0 | 两档.1，生效于注意力权重、注意力残差输出、FFN激活后及FFN残差输出；投影/位置/最终输出头无额外dropout | 保留实际位置。单层LSTM不能靠只调现有dropout字段增加正则；独立输出或变分循环dropout需新的受控比较 |
| 归一化 | 除训练输入和目标缩放，无内部BatchNorm/LayerNorm | 每编码器两处带仿射参数的Post-LN，`eps=1e-5`、`norm_first=false`；编码器外无额外final norm | 保留浅网络当前实现，不为追新同时换Pre-LN和学习率。BatchNorm会引入批内混合分布，并非通用必需项 |
| 初始化 | 原生权重/偏置为`±1/sqrt(hidden)`；股票仅首层四块输入权重改为逐gate Xavier uniform，gain=1；无正交重置、没有额外forget-bias=1 | QKV权重Xavier uniform，QKV与attention输出bias为0；其它Linear按原生fan-in均匀初始化，LayerNorm权重1/bias0，位置Embedding标准正态；股票逐层独立构造 | 初始化只调用原生构造器/nn.init；LSTM首层修正输入宽度尺度，Transformer去掉层间复制。循环权重、偏置和后层保持原生定义 |

上述默认与位置核对 [LSTM官方实现说明](https://docs.pytorch.org/docs/2.12/generated/torch.nn.LSTM.html)、
[TransformerEncoderLayer](https://docs.pytorch.org/docs/2.12/generated/torch.nn.TransformerEncoderLayer.html) 及安装源码。
以335列作为旧协议参照，小／大LSTM参数为102,721／370,305，小／大Transformer为56,321／315,777；
去重前1311列时分别为352,577／870,017和118,785／440,705；当前1276列时为343,617／852,097和116,545／436,225。这是实际模块计数，当折冻结排除不可估计列后略少。输入减少2.67%，不据此增加层数或隐藏宽度。大候选扩大的是窗口、容量和单轮计算，不仅是参数数量。

## 神经网络：损失、正则与训练

| 项目 | 实际设置 | 决定及理由 |
|---|---|---|
| loss | 平方误差；训练按每日等质量权重；每批`mean(weight*error²)` | 保留目标一致性，不换Huber或纯相关损失。无标签剪尾不等于无需考察尾部误差；改变loss须另行比较其估计目标 |
| 目标内部缩放 | 仅训练样本加权均值和总体标准差；NN训练标准化目标，预测及曲线误差换回model_target单位 | 保留，不使用验证期统计；不是取消逐日截面标签变换，也不是把最终分数恢复为原始百分比收益 |
| 优化器 | AdamW；`betas=(.9,.999)`、`eps=1e-8`、`amsgrad=false`、`maximize=false` | 保留成熟默认；未因配置省略betas就误判为未使用动量或自适应尺度 |
| 权重衰减 | `weight_decay=1e-4`，同一参数组覆盖全部可训练参数，含bias、LayerNorm仿射及位置嵌入；无额外神经网络L1/L2 loss项 | 保留温和的解耦衰减。将bias/norm免衰减或统一加至.01都是新的正则方案，当前没有隔离比较支持；不把AdamW误称为Adam加普通L2 |
| 学习率 | 两家族小候选`.0003`、大候选`.0001` | 下调，依据最佳验证轮靠前；较小学习率可能增加轮数，不能同时承诺更快或必然防止过拟合 |
| 批大小 | LSTM4096，Transformer2048，均包含最后不足一批的样本 | 保留吞吐与每轮覆盖，不丢样本；未按大batch经验线性放大学习率 |
| 顺序/随机种子 | NumPy种子42在训练行上逐epoch打乱端点；PyTorch种子42；每个端点历史内部仍有序，验证不打乱 | 保留。训练批端点shuffle不等于把未来混入历史切分；单种子不是随机种子稳定性证明 |
| 早停 | `epochs=null`、耐心10；每epoch结束对验证行均MSE作严格改善比较，恢复最佳state；首个评估点在第1轮后 | 保留无总轮数上限；不为早停靠前直接延长耐心。未做epoch0验证，不能把随机初始网络当已测基线 |
| LR调度/预热 | 无warmup、cosine、ReduceLROnPlateau或重启 | 保留固定较低步长；旧模型多数第1轮最佳，调度能继续优化训练并不保证改善预测；不叠加多个相互耦合的学习率参数 |
| 梯度处理 | 无梯度裁剪、无累积；`zero_grad(set_to_none=true)`、反传、AdamW更新 | 保留。旧记录没有梯度范数，不能诊断“爆炸”，也不能证明不存在；裁剪是有依据的工具，但没有依据指定本任务阈值1或其他值 |
| 数值与执行 | 网络和输入float32，目标/预处理统计用float64；无AMP或自定义量化；`device=cuda`，`preload_inputs=false` | 宽输入改为CPU保存float32输入、每批送GPU，模型计算仍在CUDA；不删样本、不减批大小。不把GPU内核非确定性称为模型研究噪声已消除 |
| AdamW执行默认 | `foreach=None`、`fused=None`由后端选择；`capturable=false`、`differentiable=false` | 保留库执行实现，不把这些内部执行选择全部扩展为研究网格 |

AdamW的解耦衰减依据 [Loshchilov与Hutter](https://arxiv.org/abs/1711.05101)，实际默认见
[PyTorch AdamW](https://docs.pytorch.org/docs/2.12/generated/torch.optim.AdamW.html)。
其单步衰减与学习率和步数有关，学习率下降而衰减系数不变不意味着有效收缩强度绝对不变；
本次将早停交给验证，未声称`.0001`是正则强度最优值。

耐心10的判断也核对全部44个历史NN候选，而非只看选中模型：

| 旧候选 | 最佳验证epoch分布 | 实际结束epoch分布 |
|---|---|---|
| 小LSTM | 第1轮11次 | 第11轮11次 |
| 大LSTM | 第1轮10次、第2轮1次 | 第11轮10次、第12轮1次 |
| 小Transformer | 第1轮7次、第2轮3次、第11轮1次 | 第11轮7次、第12轮3次、第21轮1次 |
| 大Transformer | 第1轮9次、第2轮1次、第6轮1次 | 第11轮9次、第12轮1次、第16轮1次 |

这些数字来自[原候选记录](../reports/data/stock-model-20d-validation.csv)。
耐心不是总epoch上限，改善后会重新计数，已允许过第11轮才达到最佳的候选。
因此不把耐心减成1—2来节约计算，也没有依据改成30来等待未观察到的长期恢复。
降低学习率后仍容许连续10次完整数据遍历无改善；若持续小幅改善则继续训练，不会在第10轮强制截断。
历史CV逐轮曲线没有保存，无法判断那次第11轮改善之前的连续平台长度，不能据此证明10是最优耐心或保证新目标不会过早停止。

## 候选数、计算代价与解释边界

每季仍为11次候选拟合加4次胜者重新拟合。日期生成器有51个候选季度；实际是否有足够合法历史由原生操作判断，
不以旧20日50期清单强行裁掉新5日可训练季度。每家族保留全部合法样本，训练推进和预测域不因本次复核缩减。

初始化调整只在构造时独立建立编码器层或初始化LSTM首层输入权重；状态大小、训练FLOP量级、推理和每季拟合次数均不变；
相对待运行配置，本次没有扩大搜索。相对旧20日，小/大神经网络步长分别变为原来的0.3／约0.333，
可能延后最佳轮数；没有固定总轮数，不能给出确定的总时长倍数。
独立初始化通过参数差异、固定种子和真实保存加载预测链验证；这些检查证明实现消费了设置，不证明5日实证更优。
其余未采用的改进不是永久排除，若后续真实诊断能区分校准、容量、优化或缺失问题，再针对该问题比较。


## 宽输入的容量、正则与实现

股票配置不重复维护四份输入名单。两个输入列字段都省略时，模型入口读取当前因子数据的原生列角色，
逐个因子优先采用对应的`feature_<因子名>`处理表示，否则采用原始因子；按名称固定列序。
显式提供任意一个输入列字段仍表示指定实验输入，空列表不触发自动扩展。
解析结果冻结为ModelSpec并写入模型事实，随后才做当折训练期全缺失/常量排除。

现有自建Barra-like五风格也作为预测输入：`feature_log_total_market_cap`（规模）、
`feature_beta_252d`（市场Beta）、`feature_momentum_252_20`（动量）、
`feature_residual_volatility_60d`（残差波动）、`feature_amihud_60d`（流动性）。
五项均存在于去重前2016Q3实际保存的Lasso输入中，本次全部保留；输入并不保证Lasso系数非零。
这些描述符先做MAD剪尾，再对行业及其余四风格做残差化、中心化和标准化；自身从风险解释列排除，避免机械消除风格信息。
其他因子的行业／风格残差与这些风格输入一起进入模型，可以分别学习独立信号和风格条件关系。
这是五个自主计算的描述符，不是商业Barra完整暴露；当前没有因补齐Barra而接入Choice财务或分析师预期。
风格暴露可以参与收益预测，但风险解释力不等于预测收益已被证明；参见[MSCI的中国风格研究](https://www.msci.com/research-and-insights/blog-post/which-factors-mattered-in-china)。

输入列数增加本身不是加深或加宽的证据。Lasso仍用三个alpha，XGBoost比较`(深度,L2)=(3,10)/(6,10)/(6,100)/(8,100)`；
`colsample_bytree=.8`、`min_child_weight=100`、`subsample=.8`、学习率`.03`及`max_bin=256`保持。
每棵树可比较的列变多，不代表允许更深的树或更小的叶质量；也不通过降低max_bin、减少行或减少候选来换容量。
Lasso的目标函数按样本质量归一化，不含除以输入列数的因子，因此不把alpha机械乘以1311／335；
输入和目标单位不变，新增相关或无效输入的影响交给训练冻结预处理、L1与原验证选择。
参数定义依据[scikit-learn Lasso](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Lasso.html)和
[XGBoost官方参数](https://xgboost.readthedocs.io/en/release_3.2.0/parameter.html)。

神经网络保留64／128隐藏维、1／2层、20／60观察窗口和既有dropout、AdamW衰减与学习率。
Transformer已有输入投影，扩大输入主要增加投影参数，不会把时间注意力的宽度自动扩大到输入列数。
LSTM首层直接消费全部输入，参数和矩阵乘法随列数增长；不能把更多输入解释为需要更多循环层。
[表格模型的系统比较](https://arxiv.org/abs/2207.08815)指出无效输入是神经网络的实际难点，
[FT-Transformer比较](https://arxiv.org/abs/2106.11959)也没有得出统一最优架构。
这些证据支持控制容量和使用验证，不证明某个新dropout比例或十倍weight decay在五日股票目标上必然更好。

LSTM原生初始化按hidden宽度缩放，输入维度增加时首层门预激活方差随输入宽度增长。
股票显式采用首层逐gate Xavier uniform，使每个hidden×input矩阵的方差按输入及输出维度确定；
它不改变sigmoid/tanh、recurrent矩阵、forget bias或网络深度。依据为[PyTorch LSTM](https://docs.pytorch.org/docs/2.12/generated/torch.nn.LSTM.html)和
[Glorot与Bengio的初始化研究](https://proceedings.mlr.press/v9/glorot10a.html)，实际训练输入诊断见[初始化表](../reports/data/stock-model-initialization.csv)。
诊断只观察初始化后的第一步、零隐状态，包含输入和循环两项偏置；`saturation_fraction`对sigmoid门定义为输出<.05或>.95，对candidate门定义为|tanh输出|>.95。它不是训练后梯度或收益比较。

训练期全缺失/常量列由现有滚动选择操作统一判断：只扫描当折合法、标签已成熟的训练样本，
把实际保留列写入候选及最终重新拟合的ModelSpec，并保存`training_selection.inputs`中的保留、全缺失和常量名单。
scaler、特征重要性、网络输入宽度和预测均消费这份冻结结果。某列后来有数据不会自动进入旧模型；
不是用全时期可用性为早期训练筛列，也不另加一套scaler动态筛选。

原始训练输入按块写入一次拟合内的标准临时Arrow IPC文件：float64数值及缺失状态不变，
宽列保持Arrow映射，按列计算精确中位数与加权统计，按块缩放；样本键、标签、顺序和序列边界另存窄表。
批次先取所需行范围的零复制slice，再按原行序take，避免小批次反复合并整列；内部数值批次复用fit入口已经建立的数值约束。公开输入边界继续解析并拒绝非法值。
序列训练行通过行位置引用完整历史，历史中不参与损失的合法观察仍保留。
Lasso复用小型Gram统计；神经网络直接生成float32输入，按批送CUDA。
临时文件在准备失败、拟合失败及成功结束时由当前调用关闭，不进入模型产物，也不是跨任务缓存。
预测所需的小型序列尾历史另有独立数值内存，输入列同时作为序列边界时也只保存一份；关闭映射后仍能保存、加载和预测。
调用进程用标准`TMPDIR`选择有足够空间的本地临时目录；代码不硬编码主机路径或资源预算。
精确中位数和加权矩仍基于全部合法训练行，不是分块中位数的平均或近似分位数。

XGBoost以原生DataIter分块消费同一训练矩阵，标签、行权重、列权重及列类型随原生接口传入。
股票配置显式`external_memory=true`时，用CUDA数组及官方`ExtMemQuantileDMatrix`把量化批次放在GPU外，
由原生后端取用；普通路径保持`QuantileDMatrix`。这个执行选项不改变树参数、缺失分支或早停规则，默认false。
GPU外存需要可选依赖组`xgboost-external-memory`，当前CUDA12项目环境使用CuPy14.2；
缺少依赖或GPU入口失败时明确报错，不静默改CPU。
依据[官方外存说明](https://xgboost.readthedocs.io/en/release_3.2.0/tutorials/external_memory.html)和
[CuPy安装说明](https://docs.cupy.dev/en/stable/install.html)。

原生分批量化与浮点求和可能有容差内的数值差异；保存的模型仍包含自身scaler与最终参数。
数值对照和容量验收分别证明计算与执行，不证明扩展输入后的预测效果；效果只能由新的逐期训练、验证和预测统计确定。

容量对照使用2014年1—6月252,197个相同合法样本、1,000个冻结有效输入、三个alpha、seed42与8线程。
原完整矩阵路径总耗时40.94秒、峰值RSS7.77GiB；最终分块路径43.15秒、4.18GiB，峰值约降低46.2%，耗时约增加5.4%。
三候选的迭代数均为10／54／259，最大系数绝对差1.18e-14，10,260行预测的最大绝对差3.41e-14。
这说明容量取舍与同负载数值保持，不能推出全部晚期窗口的耗时或GPU吞吐；完整历史训练仍需以实际运行记录评估。
