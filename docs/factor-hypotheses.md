## 统一口径

一个家族对应一个机制；具体特征还须声明观察对象、输入、观察窗口、参考基准、可用时点。
因子方向先描述数值含义，例如“越大表示越拥挤”，不提前指定正向收益或反向收益。

- **状态**：价格位置、广度、融资强度、持仓集中度等。
- **过程**：收益、订单流、补单、深度和资金变化。
- **事件**：触及、越界、回到原区间、承接恢复等，必须在当时已可观察。
- **标签**：事件或决策点之后的收益、方向、修复或延续。事后确认的失败不得回填成事前特征。
- **交互**：只表达已提出的条件假设，不做状态、窗口、市场和标签的全排列。

市场背景、行业背景和个股特征分别解释。市场变量广播到股票后仍是市场背景，
不能当作多份独立市场样本，也不应直接用逐日股票截面标准化消掉其幅度。

### 参数化回撤、历史高点与斐波那契的区别

设已知峰值为H、当前价格为P、此前上涨段的起点为L：

- 峰值回撤：`(H-P)/H`，描述从高点下跌的幅度。
- 上涨段回吐比例：`(H-P)/(H-L)`，描述此前涨幅被回吐多少，分母为零时未定义。
- 例如H=100、L=60、P=80，峰值回撤20%，上涨段回吐50%。二者不能混用。
- 若L、H来自同一滚动区间，回吐比例就是`1-价格区间位置`；共用基础量，不新增独立机制。
- 若L是事前确认且早于H的上涨起点，与窗口内任意最低点不同；不能在看见反弹后重选最佳起涨点。
- 按用户确定的口径统一使用L个交易日，首批20／60／252日；不额外建立日历52周分支。52周高点文献只提供方法参照，不声称252日与其样本定义完全一致。不同L与历史最高点仍不自动合并。
- 当前回撤与窗口内最大回撤不同。前者是当前状态，后者可能描述已经结束的历史下跌。

斐波那契比例只作明确的技术参考组，例如23.6%、38.2%、61.8%；常用50%回吐并非严格的斐波那契比例。
先保留连续回吐比例，少量比例位置用来检验是否有额外信息，不把每个比例再乘所有量价和宏观变量。
必须与相同数量、相同容忍区宽度的非斐波那契水平比较；宽区间更容易遇到反弹，不等于比例本身有预测力。

| 优先条件假设 | 经济机制与参照 | 需要验证的区别 |
|---|---|---|
| 回撤＋异常成交／冲击／承接 | 流动性供给与暂时价格压力 | 抛压继续增强，还是成交冲击已减弱；不把“大跌放量”一律视为见底 |
| 回撤＋事前持仓拥挤／基金赎回压力 | 共同持仓下的被迫交易 | 压力仍在传播，还是赎回和抛压开始缓解；要求可靠历史持仓及流量 |
| 回撤＋融资收缩／流动性恶化 | 融资与市场流动性的反馈 | 去杠杆尚在进行，还是约束已缓解；不将融资余额下降直接叫强平 |
| 回撤＋市场／行业参与变化 | 系统下跌与个股特有冲击、修复阶段 | 整体市场仍走弱，还是广度已经改善；是本轮用户假设，不视作已有A股结论 |
| 回撤＋此前趋势／市场反弹阶段 | 中期动量与恐慌后的反转条件 | 趋势内调整与大跌后的市场反弹分开；不能由动量崩溃文献推断所有深跌股必涨 |
| 历史极值位置＋成交异常／距上次极值的时间 | 锚定、注意力与交易活跃 | 重新到达旧高低点时是否有额外供需变化，且与普通位置效应比较 |

这些是有机制依据、待在目标市场和期限验证的条件假设，不是已确认有效的交互。
相关理论包括52周高点锚定、处置效应、流动性供给、融资螺旋和状态依赖反转。
特殊斐波那契比例的经济约束较弱，证据优先级低于上述机制；不根据事后图形确认“有效支撑”。

## 明确保留的条件假设

不建立通用交互库。下列关系分属上文家族，计算基础量只保留一个owner：

| 条件关系 | 要区分的机制 | 不再重复增加 |
|---|---|---|
| 压缩后出现方向性交易 | 新需求推动与短暂冲击 | 多个同义横盘分分别乘所有订单流 |
| 高换手但价格反应弱 | 承接／供给与显著价格冲击 | 与已有承接公式完全等价的另一“吸筹分” |
| 事前高低位＋异常量＋短期冲击 | 低位反应与高位反应 | 未提出假设的所有正负、窗口组合 |
| 回撤／残差回撤＋异常成交＋恢复 | 抛压继续与抛压缓解 | 没有强平事实却命名“真实清算” |
| 过去强势＋市场参与收缩 | 孤立领涨与广泛上涨 | 离散度、HHI、排名等无明确机制的连乘 |
| 拥挤＋回撤／同步退出 | 集中暴露遭遇冲击 | 将交易集中与持仓集中合成真值 |
| 融资强度＋回撤＋流动性恶化 | 去杠杆压力与普通下跌 | 用融资余额变化伪造强平订单 |
| 已知ETF份额变化＋历史篮子 | 被动资金压力 | 当前权重倒填、把份额变动直接叫现金流 |
| 美国冲击＋相应历史暴露 | 相同外部冲击下的个股差异 | 用A股市场Beta替代对应美国变量Beta |
| 接近关键价位＋可观察承接 | 位置效应与真实供需变化 | 仅凭触及前高就预设看空 |
| 低开＋早盘承接／背景 | 缺口修复与继续走弱 | 把当天完整成交量、最高最低和收盘提前使用 |

| 当日开盘至收盘 | 开盘事件接口待补 | 只能配开盘时已知特征；与“次日日内”定义相似但决策坐标不同，不能直接合并 |
| 开盘后观察点至后续时段／收盘 | 待补 | 5／15／30分钟观察所得特征，只预测观察结束后的收益 |
| 未来中间价收益及方向 | 原有3／30／60秒，30秒为已定基线 | 同连续交易段内真实未来报价；保留成熟时间、报价年龄和超期规则 |
| 突破失败、回踩结果、恢复时间 | 待明确事件标签接口 | 未来确认时间属于成熟时点；不得将后来结局当作事件起点特征 |

标签候选用于预先说明要回答的问题，不按历史表现挑期限。完成上述代码与审查验收后，
按最新授权在服务器生成真实因子／标签并计算IC、RankIC及风险中性化对照；
本次研究阶段不自动扩展至训练、预测、优化、回测或归因。

## 工程收敛与输入边界

1. 量价、关键价位、日线成交密集区复用现有量价owner；盘口、逐笔事件复用现有高频owner。
2. 风格与残差共用现有风险模型；市场／行业聚合使用完整历史证券域和PIT分类，个股同行参照排除自身。
3. 同一算子不同窗口共用实现，保留有独立机制的时间尺度。日频与高频共用机制和元数据，数据与时钟不强行统一。
4. 已有宏观历史变换、跨市场时钟、Beta和数据处理模块优先复用，不新增第二套因子引擎或编排系统。
5. 下载与图片／PDF／网页文档提取在仓库外；仓库仅接收结构化raw并准备interim，保留来源、原件哈希和提取关系。
6. “已获得原件”“适配器已有代码”“interim已验证”“因子已有代码”“真实研究已运行”分别记录。
7. 需要历史权重、真实发布时点、机构身份或行业映射而无法免费可靠获取的，只阻塞依赖它们的计算；保留具体输入条件，不建立返回空值的占位实现。
8. 历史发布时间缺失时查证官方发布规则及异常延迟，允许记录有依据的保守可用时点；实际发布时间保持缺失，估计规则、依据和置信限制单列，不将采集日当成历史发布日期。

## 本轮预处理与评价口径

去极值、标准化和中性化逐因子决定并在服务器实际研究配置中保存；不按标签表现选处理方式。
相同处理方案可用现有FeatureTransformSpec与显式批次共用，不新增预处理引擎。
原始因子始终保留；预处理失败只影响该处理版本，不抹掉原值和其他因子的评价。

| 变量性质 | 去极值 | 标准化／中性化与解释 |
|---|---|---|
| 个股连续无界的收益、波动、冲击、成交活跃和杠杆特征 | 默认现有MAD；真正极端事件保留原值对照 | 同时点完整有效股票截面标准化；另做行业＋五风格风险残差后标准化 |
| 价格区间位置、占比、HHI、方向不平衡等有界变量 | 默认不裁剪有效边界 | 个股截面版本通常标准化；边界和单调含义保留原值；常数处理见[处理口径](factor-treatment.md#逐列处理的含义) |
| 假突破幅度、回撤压力等含大量真实零的事件变量 | 保留事件零与幅度，逐项检查尾部；不把零当缺失 | 比较发生率、发生后的幅度及全体关系；不以分位分组打散相同零值 |
| 市场广度、宏观及行业广播背景 | 不按股票数量重复裁剪；已有历史标准分或分位不重复变换 | 纯市场变量做时序；行业变量做行业层评价。行业哑变量可完全消除行业广播量，不能将零残差包装成选股因子 |
| 高频股票的价差、深度、成交量和等待时间 | 无界量按经济单位评估MAD；合法极端流动性事件保留原值对照 | 先按相对价格、深度等定义消除量纲，再按同步决策点做股票截面处理；风险暴露仅使用决策前可得日频事实 |
| 四只ETF的高频时序 | 不用全样本未来分位裁剪；有界量保留 | 各ETF分别评价，必要历史缩放仅用此前交易日或此前观察窗口；不对四只横向zscore，不强套股票行业风格 |
| 机制相同但仅差负号、单调变换的列 | 不以重复处理制造独立假设 | 明确等价关系；相同样本的RankIC不重复计数，原始Pearson含义另行说明 |

三条研究线分别执行，不拼成同一评价样本：

| 研究线 | 截面／时序样本 | 风险处理与统计单位 |
|---|---|---|
| 低频股票截面 | 每个信号交易日的历史有效股票，主标签1／5／20日及次日开盘至收盘 | 比较原值、去极值／截面标准化、行业＋五风格中性化；并比较原始收益与未来收益风险残差；IC按信号日聚合，多日重叠用HAC等序列相关修正 |
| 高频股票截面 | 同步3秒决策点的沪深全A，不含北交；主标签30秒，3／60秒补充 | 同步截面预处理；风险暴露仅取此前可得日频事实，中性化结果与未中性化并列；日内IC先按日汇总，推断以交易日为块 |
| 高频ETF时序 | 四只分别做单资产日内时序，黄金ETF独立解释 | 不用四只之间的截面zscore，也不套股票行业回归；需要缩放时只用过去数据，同日内时序IC按交易日汇总；可识别的基准暴露仅作单独对照 |

市场广度和行业广播量保留原幅度，由各自定义owner识别；默认特征拼装要求保留raw组，
不会将它们转换成个股选股残差。`leader_breadth_fragility`在同日只是正动量乘共同非负
市场状态，不能当作新增独立RankIC假设；检验重点是条件状态与后续收益关系。
风险模型自身的五类风格暴露单列为风险基线；对其自身回归产生的机械消除或零残差
不解释为新选股信息。保留原值／标准化版本，风险残差对照若退化则明确标记未定义。

主分析报告覆盖、缺失原因、截面IC／RankIC或ETF日内时序IC／RankIC、分层未来收益关系、
逐年与市场状态稳定性、因子自相关及必要的不确定性。高频推断以交易日为独立统计块，
不把数百万相邻报价当独立样本；多日标签按重叠期限处理序列相关性。分层收益是标签统计，
不构建持仓、成交、净值或回测结论。未知、样本不足及常数导致的相关未定义保留原因，不以零相关代替。

## 方法参考与适用边界

- [Lo、Mamaysky、Wang，Journal of Finance 2000](https://www.nber.org/papers/w7613)：技术形态须客观定义。不是A股支撑压力有效性的现成证明。
- [Osler，Journal of Finance 2003](https://www.newyorkfed.org/research/staff_reports/sr125.html)：订单聚集与支撑阻力机制；原研究为外汇，不能直接解释A股投资者身份或止损订单。
- [Cont、Kukanov、Stoikov，订单簿价格冲击](https://arxiv.org/abs/1011.6402)：OFI与市场深度，适用于H01／H05的方法参考。
- [Gould、Bonart，盘口不平衡](https://arxiv.org/abs/1512.03492)：下一次价格变化的盘口信息；期限与A股30秒预测不同。
- [Cont、Cucuringu、Zhang，跨资产OFI](https://arxiv.org/abs/2112.13213)：区分同期解释与滞后传导；不据此增加全市场稠密配对。
- [Large，Journal of Financial Markets 2007](https://www.sciencedirect.com/science/article/pii/S1386418106000528)：恢复的可靠程度和速度是不同维度，恢复结局不能提前使用。
- [Nagel，Review of Financial Studies 2012](https://www.nber.org/papers/w17653)：流动性供给与反转的状态依赖，不能直接当作A股同期限结论。
- [Coval、Stafford，Journal of Financial Economics 2007](https://www.nber.org/papers/w11357)：基金流量、共同持仓和被迫交易压力；需要真实流量和历史持仓。
- [Grinblatt、Han，Journal of Financial Economics 2005](https://www.sciencedirect.com/science/article/pii/S0304405X05000747)：持仓参考价／处置效应模型；日线成交密集区本身不是其真实持仓成本。
- [Ben-David、Franzoni、Moussawi，ETF与波动](https://www.nber.org/papers/w20071)：ETF交易冲击传导的方法依据，不能将份额变化直接认定为实际成分股买卖。
- [中国市场日内反转机制，JEDC 2022](https://www.sciencedirect.com/science/article/pii/S0165188922000185)：提示不同市场和持有期限可能有不同机制，不机械移植美国反转解释。
- [Volume Profile价格区间分配说明](https://www.tradingview.com/charting-library-docs/latest/trading_terminal/session-volume-profile/)：区间重叠分配保持成交总量；日线比低周期数据更粗，是实现参考而非盈利证据。
- [George、Hwang，Journal of Finance 2004](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.1540-6261.2004.00695.x)：52周高点与动量／锚定；不证明越大回撤必然带来反弹。
- [Huddart、Lang、Yetman，Management Science 2009](https://pubsonline.informs.org/doi/10.1287/mnsc.1080.0920)：过去52周极值、距极值的时间与交易活跃；不是斐波那契特殊比例证据。
- [Li、Yu，Journal of Financial Economics 2012](https://www.sciencedirect.com/science/article/pii/S0304405X11002121)：52周高点与历史最高点的锚定含义可以不同，支持保留不同参考尺度。
- [Brunnermeier、Pedersen，Review of Financial Studies 2009](https://www.nber.org/papers/w12939)：融资与市场流动性互相强化的模型，提供回撤与去杠杆条件假设，不直接验证A股融资指标。
- [Daniel、Moskowitz，Momentum Crashes](https://www.nber.org/papers/w20439)：恐慌状态与市场反弹下的动量风险，不是个股大回撤后的普遍看多结论。
- [Tsinaslanidis等，斐波那契回撤实证](https://www.sciencedirect.com/science/article/pii/S0957417421012495)：三个股市样本中未发现特殊比例区域相对非斐波那契区域的显著优势，提示须有公平对照。
